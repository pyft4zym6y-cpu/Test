# Индустриальные эталоны, против которых сверяется каждый вид аудита

Источники: Baymard Institute, Nielsen Norman Group, Semrush/Ahrefs, GEO-исследования 2025–2026, WiderFunnel LIFT, BrowserStack/TestGrid. Цифры из вендорских блогов — «ориентир» (порядок величины), нормативно жёсткие: пороги Core Web Vitals (Google), шкала серьёзности 0–4 (Nielsen), данные Baymard по чекауту.

## UX (эталон: Baymard 650+ гайдлайнов, NN/g)
- Чекаут-эталон: **12–14 элементов формы (7–8 полей)**; средний сайт — 23,5 элемента; сокращение форм на 20–60% возможно почти всегда. Устранение задокументированных проблем чекаута — до **+35%** к конверсии (Baymard). Средний abandonment корзины ~70%; ~1 из 5 бросает из-за длинного чекаута.
- Только 49% сайтов имеют приличный UX карточки; 58–78% сайтов — посредственные листинги/фильтры (Baymard). Значит «у всех так» — не аргумент.
- Серьёзность находок — шкала Нильсена 0–4 (частота × влияние × устойчивость): 4 = катастрофа (чинить до релиза), 3 = мажорная, 2 = минорная, 1 = косметика.
- Гостевой чекаут обязателен; принудительная регистрация — ~19% брошенных (ориентир).

## SEO (эталон: Semrush 140+ проверок, Ahrefs 16 шагов)
- Четыре макро-области полного аудита: 1) crawlability/indexability (robots, sitemap, canonical, noindex, глубина, сироты); 2) техническая производительность (CWV, HTTPS, дубли); 3) on-page и контент (title/desc/H1, интент, каннибализация); 4) видимость и авторитет (позиции, ссылки).
- Пороги Core Web Vitals: LCP < 2,5 c; INP ≤ 200 мс; CLS ≤ 0,1 — по 75-му перцентилю CrUX. INP — самый часто проваливаемый (~43% сайтов).
- Приоритизация рекомендаций — матрица Impact/Effort: quick wins в первую очередь, low-impact/high-effort отклонять. Errors/Warnings/Notices — базовая сетка серьёзности.

## GEO/AEO (AI-выдача, 2025–2026)
- Технический слой: AI-краулеры не заблокированы в robots.txt (GPTBot, OAI-SearchBot, ClaudeBot, PerplexityBot, Google-Extended); llms.txt в корне; контент доступен без JS (статический HTML со schema парсится ~94%, JS-рендер ~23% — ориентир).
- Цитируемость пассажей: самодостаточные блоки 40–100 слов, ответ первым абзацем под заголовком-вопросом, факт-плотность (цифры, даты, источники), таблицы/списки — +28–40% к цитированию (ориентир).
- JSON-LD (Product, Offer, FAQPage, Organization, Author) поднимает точность извлечения фактов LLM с ~16% до ~54% (ориентир).
- E-E-A-T: страницы с сильными сигналами в 2,3× чаще цитируются в AI Overviews; авторские страницы с биографией, сторонние упоминания, свежесть.

## CRO (эталон: LIFT, PIE/ICE)
- LIFT: 6 факторов конверсии — Value Proposition (ядро), Relevance, Clarity, Urgency поднимают; Anxiety и Distraction тянут вниз. Каждую страницу пути оценивать по всем шести.
- Приоритизация: PIE (Potential × Importance × Ease) — для выбора страниц; ICE (Impact × Confidence × Ease) — для гипотез. Гипотеза формата «если изменим X, то Y, потому что Z».
- Полный CRO-аудит: цели/KPI → аудит аналитики → funnel-анализ (drop-off по шагам, mobile vs desktop) → поведенческие данные (rage clicks) → эвристика → голос клиента → технический слой → гипотезы → roadmap тестов.

## Маркетинговые механики (ориентиры эффектов)
- Upsell+cross-sell +10–30% выручки (McKinsey); прогресс-бар бесплатной доставки +17–30% AOV; порог бесплатной доставки ≈ AOV+30%; BNPL +20–30% конверсии и +30–50% чека; отзывы на PDP +60% конверсии; UGC ~+102%; квизы ×3 к конверсии против прямого PDP; back-in-stock: open ~65%, конверсия ~22%; abandoned-cart email recovery ~10%, отправка в течение часа +20%; wishlist-триггеры ×2–3 против промо-рассылок. Все — ориентиры для приоритизации, не обещания.

## Journey-тестирование (эталон walk-through)
- Тестируются сквозные пути, не фичи: вход → поиск (точный, синоним, опечатка, нулевая выдача) → фильтры (комбинации, сброс, честные счётчики) → PDP (варианты, наличие, фидбек добавления) → корзина (пересчёт, промокод, прозрачность доставки) → чекаут (гость, валидация, сохранение данных при ошибке, двойной клик «оплатить») → подтверждение.
- Все тупики проверяются на наличие выхода: пустая корзина, нулевой поиск, 404, ошибка оплаты, out-of-stock. Кнопка «назад» и обновление страницы в чекауте не должны терять прогресс.
- Фиксация: шаги, ожидаемый/фактический результат, серьёзность 0–4, устройство. Mobile-абандон ~86% против ~74% desktop — мобильный проход обязателен на A1.
