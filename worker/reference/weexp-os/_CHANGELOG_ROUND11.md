# Раунд 11 · первый живой прогон · lanavitta.com

Пятое условие готовности — «Проверенность» — впервые получило попытку. Слой L0, без клиента и без доступов, строго по протоколу.

Отчёт: `projects/lanavitta/RUN-01-L0-report.md`. Находки по контракту: `projects/lanavitta/findings.json`, записи покрытия: `coverage.json`.

## Восемь находок у клиента

Валидацию контракта прошли с первого раза, ноль ошибок. Тяжелейшая — контактный e-mail в подвале начинается с кириллической «с» (U+0441): строка выглядит как адрес, но им не является, письма не доходят, и это верно всё время, пока строка существует в шаблоне. Вторая — при приёме оплаты картой на сайте нет договора купли-продажи: единственный документ определяет сайт как информационный ресурс, срок и порядок возврата не указаны.

## Пять дефектов плагина за один прогон

3000 синтетических прогонов раунда 10 не нашли ни одного. Живой нашёл пять.

| дефект | суть | статус |
|---|---|---|
| объект для основного выхода | `ux-os` владел только `Experiment`, а постраничный разбор описывает страницу | исправлено: объект `Page` |
| потолок доказательства на L0 | правило смешивало «нет доступа к данным клиента» с «нет доказательства» | исправлено: потолок разделён на факт E4 / интерпретацию E2 / косвенный вывод E1 |
| вырожденный случай экономики | на L0 денежной оценки нет ни у одной находки, шаг 3 не выполнялся | исправлено: правило и запрет придумывать число |
| приоритет без экономики | шаг 5 требует остаточный вклад, которого нет | исправлено: запасной порядок с обязательной пометкой |
| ключ группировки | ловит совпадение, но не родство: три правовые находки не сгруппировались | открыто, OQ-013 — чинить после второго прогона |

Урок раунда: проверка «у скила есть объект» не заменяет проверку «объект соответствует тому, что скил выпускает». Первое ловит валидатор, второе — только клиент.

## Первая сходимость модели с фактом

Симулятор предсказывал покрытие на L0 около 60%. Факт: 7 доменов проверено, 6 заблокировано слоем, 1 не запускался. Сошлось.

## Условие «Проверенность» не закрыто

Пройден один слой из пяти. Находки не подтверждены клиентом, ни одна рекомендация не внедрена, факта нет. Закрытие требует L1–L2 и возврата на L4 через квартал.
