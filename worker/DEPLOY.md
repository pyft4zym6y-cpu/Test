# Разворачивание аудит-сервера

Чтобы запускать аудит **кнопкой из портала** (без терминала), сервер поднимается
один раз. Ниже — способ **без разработчика, мышкой через сайт Railway**
(вход через Google — не нужен ни GitHub-вход, ни письмо на почту).

---

## БЕЗ РАЗРАБОТЧИКА — через Railway (мышкой, ~15 минут) ⭐ рекомендую

Один раз настраиваете, дальше работаете только кнопкой в портале.

### Что нужно заранее
- Аккаунт **Google** (Gmail) — для входа в Railway в один клик.
- **Ключ Claude** с балансом: console.anthropic.com → API keys (создать **новый**)
  и Billing → пополнить (хватит $5–10).
- Ваш репозиторий на GitHub (уже есть), ветка **`claude/ai-assistant-comerc-oc-qufqcc`**.

### Шаги
1. Откройте **railway.com** → **Login** → **Continue with Google** (входите Gmail).
2. Нажмите **New Project** → **Deploy from GitHub repo**.
   - Railway попросит один раз разрешить доступ к GitHub — нажмите **Configure
     GitHub App**, выберите репозиторий **`Test`**, **Install/Save**. Вернётесь в Railway.
3. В списке выберите репозиторий **`Test`**. Railway создаст сервис.
4. Откройте сервис → вкладка **Settings**:
   - **Source → Branch**: выберите **`claude/ai-assistant-comerc-oc-qufqcc`**.
   - **Build**: Railway сам увидит файл `railway.json` и соберёт по нашему
     `worker/Dockerfile` (браузер уже внутри). Ничего вводить не надо.
5. Вкладка **Variables** → добавьте три переменные (**New Variable**):
   | Имя | Значение |
   | --- | --- |
   | `ANTHROPIC_API_KEY` | ваш **новый** ключ Claude |
   | `AUDIT_SERVER_TOKEN` | любой длинный пароль, придумайте сами (напр. 20+ символов) |
   | `AUDIT_MODEL` | `claude-opus-5` |
   > `AUDIT_SERVER_TOKEN` — это ваш секрет: его же вставите в портал на шаге 8.
   > Сохраните его себе.
6. Вкладка **Settings → Networking** → **Generate Domain** (порт `8787`).
   Появится адрес вида `https://weexp-audit-production.up.railway.app`.
   **Скопируйте его.**
7. Дождитесь, пока деплой станет **зелёным** (Active) — первая сборка 5–10 мин.
   Проверка: откройте `https://…up.railway.app/health` — должно быть
   `{"ok":true,"hasKey":true}` (сервер жив и ключ на месте).
8. **Подключить к порталу:** в портале ссылка **«Запустить аудит»** (вверху, видна
   вам как админу) → раскройте **«Настройка сервера (один раз)»**:
   - **Адрес аудит-сервера** = адрес с шага 6
   - **Токен** = `AUDIT_SERVER_TOKEN` с шага 5
   - **Проверить связь** → «сервер на связи · ключ Claude: есть ✓».

Готово. Теперь: URL клиента → **Запустить аудит** → скачиваете `AD-15.pptx` и
`audit-report.docx`.

### Сколько стоит
- Railway: бесплатный пробный кредит на старт, дальше ~**$5/мес** подписка +
  оплата по факту работы (память ~1 ГБ под браузер). Реально выходит немного,
  т.к. сервер работает только когда запускаете аудит.
- Claude — по факту, **центы за аудит** на дорогой модели; ваши $5–10 надолго.

> ⚠️ Ключ, который вы присылали в переписке, считайте скомпрометированным:
> зайдите в console.anthropic.com → API keys → **удалите (Revoke) его** и
> создайте **новый** — именно новый вставляйте в шаг 5. Никогда не присылайте
> ключ в чат.

## Альтернатива — через Render (если Railway не подошёл)

Один раз настраиваете, дальше работаете только кнопкой в портале.

### Что нужно заранее
- Аккаунт **GitHub** (у вас уже есть — репозиторий там).
- **Ключ Claude** с балансом: console.anthropic.com → API keys (создать новый) и
  Billing → пополнить (хватит $5–10).
- Аккаунт на **render.com** (регистрация через тот же GitHub — 1 клик).

### Шаги
1. Зайдите на **render.com**, войдите через **GitHub**.
2. Вверху **New → Blueprint**.
3. Render покажет ваши репозитории → выберите **`Test`** (pyft4zym6y-cpu/Test).
4. В поле ветки выберите **`claude/ai-assistant-comerc-oc-qufqcc`**.
   Render найдёт файл `render.yaml` и предложит создать сервис **weexp-audit**.
5. Он попросит ввести **ANTHROPIC_API_KEY** — вставьте свой ключ Claude.
   (Токен `AUDIT_SERVER_TOKEN` Render создаст сам — понадобится на шаге 8.)
6. Нажмите **Apply / Create**. Пойдёт сборка — 5–10 минут (готовит браузер внутри).
7. Когда статус станет **Live**, вверху будет адрес вида
   `https://weexp-audit.onrender.com`. **Скопируйте его.**
   Проверка: откройте `https://…onrender.com/health` — должно быть
   `{"ok":true,"hasKey":true}` (значит сервер и ключ на месте).
8. Скопируйте токен: в сервисе → вкладка **Environment** → строка
   **AUDIT_SERVER_TOKEN** → значение (глазик «показать»). Это ваш токен.

### Подключить к порталу (тоже мышкой)
1. В портале — ссылка **«Запустить аудит»** (вверху, видна вам как админу).
2. Раскройте **«Настройка сервера (один раз)»**:
   - **Адрес аудит-сервера** = адрес с шага 7 (`https://…onrender.com`)
   - **Токен** = значение с шага 8
   - **Проверить связь** → «сервер на связи · ключ Claude: есть ✓».
3. Готово. Теперь: URL клиента → **Запустить аудит** → скачиваете `AD-15.pptx`
   и `audit-report.docx`.

### Сколько стоит
- Хостинг Render (нужен план **Standard**, ~1 ГБ памяти для браузера) — порядка
  **$25/мес**. На меньшем плане (Starter, 512 МБ) браузер может падать.
- Claude — по факту, **центы за аудит** на дорогой модели; ваши $5–10 надолго.

> Первый запрос после простоя может «просыпаться» ~30 сек — это норм для Render.

## Для разработчика — Railway / VPS (Docker)

Тот же образ (`worker/Dockerfile`), собирать из **корня репозитория**:
```bash
docker build -f worker/Dockerfile -t weexp-audit .
docker run -d -p 8787:8787 \
  -e ANTHROPIC_API_KEY=sk-ant-... \
  -e AUDIT_SERVER_TOKEN=секрет \
  -e AUDIT_MODEL=claude-opus-5 \
  weexp-audit
curl http://localhost:8787/health
```
Railway: New → Deploy from GitHub → Dockerfile `worker/Dockerfile`, context — корень; те же переменные. Поставьте HTTPS-прокси (портал ходит по https).

## Эндпоинты
- `GET /health` — статус + есть ли ключ.
- `POST /audit` — `{tier,site,competitors,request,agentic,prelaunch,brief,answers,baseline}`; заголовок `x-audit-token`.
- `GET /result/:id/:file?t=токен` — скачать файл.

## Безопасность
Токен — не публичный, живёт в переменных окружения сервера. Файлы отдаются только по токену.
