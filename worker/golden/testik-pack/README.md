# Golden pack «Тестик» — еталон пакета: 5 ємких звітів

Пакет v2: 5 самодостатніх звітів зі змістами (Презентація 18 слайдів · Діагностика: 12 аудитів, 33 стор. · Фінансовий: міст P&L + DoD · Роадмапа: тижнева W1 + ресурсна модель + ризики + автономність · Пропозиція та передача). Змодельовано на синтетичній компанії «Тестик»
(D2C посуд, €123k/міс, UA-сайт + Allegro PL). Це **золотий еталон якості**
для генераторів рушія: структура, тон, вёрстка і методологічна дисципліна,
до яких мають прагнути автоматичні звіти.

## Що робить пакет еталонним (перевіряй свої звіти по цих пунктах)

1. **Одна легенда — нуль суперечностей.** €433k із a10 = ті самі 8 важелів,
   що деталізовані в a06–a08, розкладені в a11/a12/a15 і перетворені на пороги a17.
2. **Заголовок = висновок**, не тема («Хвороба не в маркетингу. У даних і організації»).
3. **Жодної цифри без джерела**; де джерела немає — позначка «очікує погодження»
   (у пакеті таких дві: собівартість по SKU, GPSR-договір).
4. **Метод без подвійного рахунку**: max-важіль + 45% решти; чутливість ±; розділ
   «чого в оцінці НЕМАЄ свідомо».
5. **Обмеження клієнта поважаються**: заморожена платформа, бюджет €6k/міс,
   ємність команди — план не виходить за них.
6. **«Що вже пробували» → жодна рекомендація не повторює невдалу спробу
   без пояснення, що інакше.**
7. **DoD-дисципліна**: цільова модель = 24 вимірні пороги «пройдено/ні»,
   вкл. тест «3 тижні відпустки власника без падіння метрик».
8. **Самооцінка vs дані** — розриви анкети й фактів показуються поруч (продає чесність).
9. Кожна сторінка синтетичного пакета маркована «ПРОТОТИП · СИНТЕТИЧНІ ДАНІ» —
   у бойових звітах цю плашку замінює рядок клієнта.
