## Внешние скилы, встроенные в систему (`.claude/skills/`)

- **playwright-cli** (Microsoft) — токен-эффективная браузерная автоматизация для ручной доразведки, отладки селекторов, воспроизведения багов обхода.
- **Strix** (4 скила, usestrix) — автономный AI-пентест. Роль в системе: агент №19, закрывает глубину аудита безопасности (сейчас QA помечает наш security-слой как поверхностный и делегирует Strix на A2). Managed-режим (`managed-pentesting-with-strix`) работает без Docker и локального LLM-ключа — подходит для этой облачной среды; OSS-режим — Docker + BYO-ключ. **Юридический гейт: пентест запускается только против ресурсов клиента с письменной авторизацией владельца** — это встроено в резолюцию QA-находки безопасности.

## Контур качества (правило системы)

После сборки пакета ВСЕГДА выполняется: **синергия → сверка → расследование → резолюция**.
Любая нестыковка (числа, трактовки, логика), найденная в любом прогоне, автоматически: (1) фиксируется в дебаг-журнале, (2) попадает в Протокол синергии/QA, (3) расследуется аналитическим слоем до внятной трактовки, (4) либо закрывается авто-исправлением, либо становится задачей с владельцем. Документ, вышедший из системы, не должен нуждаться в ручной проверке на противоречия.
