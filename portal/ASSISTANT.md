# AI-со-пилот аудита Commerce OS

Полноценный ассистент, встроенный в Discovery-портал. Помогает вести аудит:
объясняет Health Score, переводит разрывы в деньги, подбирает плейбуки, готовит
вопросы клиенту и куски отчёта/КП — **строго по текущему состоянию аудита**, а не
из головы.

Доступен на всех страницах портала кнопкой **«◆ Со-пилот аудита»** (правый нижний
угол). Открывается панелью чата с подсказками.

## Гибридная архитектура

Ассистент разделён на два слоя — так числа остаются доказуемыми, а язык живым:

1. **Детерминированное ядро** (`src/lib/assistant.ts`). Собирает «снимок аудита»
   из тех же движков, что и страницы портала:
   - `buildReport` → Health Score (A-зрелость + B-разрывы), покрытие опросника,
     критические разрывы, топ-проблемы, активированные правила роутинга;
   - `runDecisions` → приоритетные решения с трассой «почему» (impact/сложность,
     срок, плейбуки, ROI);
   - `forecast` + `gapCosts` → недополученный оборот, прогноз 12 мес, цена
     бездействия по каждому разрыву;
   - `detectContradictions` → противоречия в ответах;
   - `computeConfidence` → уверенность в выводах.

   Снимок сериализуется в текст (`snapshotToContext`) и передаётся модели как
   **ground truth**. То же ядро умеет отвечать офлайн (`localAnswer`) на типовые
   вопросы — без обращения к LLM.

2. **LLM-слой** (`api/assistant.js`, Vercel serverless). Проксирует чат в Claude
   API, подмешивая персону метода Commerce OS (ДНК: факт→зона→эталон→разрыв→
   деньги→плейбук; считать в обороте; не складывать рычаги воронки; помечать
   факт/допущение) и снимок аудита. Модель объясняет и рассуждает — числа берёт
   из снимка и не пересчитывает. Ответ отдаётся потоком (streaming).

### Почему так

Владелец ловит консультанта на первой же выдуманной цифре. Держать расчёты в
детерминированном движке, а язык — в LLM, значит: цифры на экране всегда сходятся
с отчётом, КП и таблицей аудита, а ассистент при этом ведёт живой диалог и
объясняет метод.

## Режимы работы

| Условие | Поведение |
| --- | --- |
| `ANTHROPIC_API_KEY` задан | Развёрнутый диалог через Claude API поверх снимка аудита. |
| Ключа нет / сеть недоступна | Офлайн-движок: детерминированные ответы по снимку (Health Score, деньги, приоритеты, разрывы, противоречия, покрытие). Помечается «офлайн-режим». |
| Аудит пуст | Ассистент честно говорит, что данных нет, и что заполнить/какой доступ запросить. |

## Настройка

Vercel → Settings → Environment Variables (проект портала):

- `ANTHROPIC_API_KEY` — ключ Claude API (обязателен для LLM-режима).
- `ASSISTANT_MODEL` — необязательно, по умолчанию `claude-opus-5`.

В демо-режиме портала (без Supabase) со-пилот тоже работает: снимок берётся из
локальных данных браузера, а при отсутствии ключа отвечает офлайн-движок.

## Что спрашивать

- «Какой Health Score и что он значит?»
- «С чего начать — приоритетное решение?»
- «Сколько недополучаем оборота? Дай прогноз на 12 месяцев.»
- «Какие критические разрывы и их цена бездействия?»
- «Есть ли противоречия в ответах клиента?»
- «Что запросить у клиента дальше, чтобы поднять доверие к выводам?»

| Файл | Роль |
