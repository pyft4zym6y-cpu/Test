CAUSAL MAP
От симптома к корневой причине, оттуда к деньгам и приоритету
12 узлов · цепочка из пяти звеньев · дерево зависимостей метрик

## Зачем

Реестр болей группирует находки по причине, но не показывает **цепочку**. Низкий LTV
может идти от CRM, ассортимента, цены или логистики — и без карты выбор делает
интуиция консультанта.

Каждый узел разбирается по пяти звеньям:

```
Симптом → Корневая причина → Вторичные причины → Бизнес-эффект → Деньги → Приоритет
```

**Правило работы.** Симптом никогда не адресуется плейбуком напрямую. Сначала
спускаемся до корневой причины, и только она получает плейбук. Если корневых причин
несколько, разделяем вклад — иначе один и тот же разрыв посчитается дважды.

## Дерево зависимостей метрик

Из чего что вытекает. Стрелка означает «влияет на», не «коррелирует».

```
Техфундамент ──► Индексация ──► Органический трафик ─┐
Дерево и фасеты ──► Находимость ─────────────────────┤
Контент карточки ──► Add-to-cart ──► CR ─────────────┼──► Заказы ──┐
Чекаут ──► Завершение оформления ────────────────────┘             │
Оплата заявок ──────────────────────────────────────────────────►  ├──► Выручка
Выкуп (отказы × возвраты) ──────────────────────────────────────►  │
Ассортимент и цена ──► Средний чек ─────────────────────────────►  │
                                                                    │
Retention-контур ──► Доля повторных ──► LTV ──┬──► LTV:CAC ────────┘
Качество продукта ──► NPS ──► Повторные ──────┘        ▲
Каналы и креативы ──► CAC ─────────────────────────────┘
Цена и промо ──► Маржа ──► Порог ROAS ──► Допустимый CAC
Оборачиваемость ──► Оборотный капитал ──► Способность расти
```

**Два следствия, которые обычно упускают.** Маржа управляет допустимым CAC, а не
наоборот: сначала считается порог, потом покупается трафик. И оборотный капитал
ограничивает рост сильнее, чем спрос — бизнес может упереться в деньги, а не в
покупателей.

## Узлы

### 01 · Низкий LTV

| Звено | Содержание |
| --- | --- |
| Симптом | Клиенты покупают один раз |
| Корневые причины | Нет retention-контура · товар не предполагает повторной покупки · клиент не принадлежит бренду (продажи через площадки) |
| Вторичные | Нет сегментации · нет сценариев после покупки · неизвестен цикл потребления · база не собирается |
| Бизнес-эффект | Весь рост зависит от платного трафика; LTV:CAC не растёт |
| Деньги | База × доля повторных × чек × частота |
| Плейбуки | PB-08, PB-43, PB-09, PB-45 |

**Развилка.** Если товар действительно разовый — корневая причина не в CRM, а в
ассортименте: нужны сопутствующие категории (PB-42, PB-28), а не письма.

### 02 · Низкая конверсия сайта

| Звено | Содержание |
| --- | --- |
| Симптом | CR ниже нормы бракета чека |
| Корневые причины | Товар не находится · возражение категории не снято · чекаут теряет · трафик нецелевой |
| Вторичные | Фасеты отсутствуют или скрыты · мало фото · нет масштаба · длинный чекаут · дорогая доставка вскрывается поздно |
| Бизнес-эффект | Каждый вложенный в трафик рубль отрабатывает хуже возможного |
| Деньги | Трафик × ΔCR × чек × оплата × выкуп |
| Плейбуки | PB-02 → PB-15, PB-05 |

**Порядок обязателен.** Сначала PB-02 разбирает воронку и говорит, на каком шаге
теряем. Тесты до этого — работа вслепую.

### 03 · Растущий CAC

| Звено | Содержание |
| --- | --- |
| Симптом | Привлечение дорожает, объём не растёт |
| Корневые причины | Аукцион вырос · креативы выгорели · структура кабинета неверна · нет органики и бренда как бесплатного источника |
| Вторичные | Аудитории пересекаются · нет исключений · брендовый трафик засчитывается платному · порог ROAS считается от выручки |
| Бизнес-эффект | Рост упирается в бюджет; при остановке рекламы продажи падают почти до нуля |
| Деньги | Разница между текущим CAC и допустимым по марже × число заказов |
| Плейбуки | PB-57, PB-03, PB-04, PB-37 |

### 04 · Низкий средний чек

| Звено | Содержание |
| --- | --- |
| Симптом | Чек не растёт или падает |
| Корневые причины | Ассортимент смещён в дешёвый сегмент · нет допродаж · промо приучило к скидке |
| Вторичные | Нет комплектов и наборов · порог бесплатной доставки не поддержан подсказкой · рекомендации не работают |
| Бизнес-эффект | Юнит-экономика не выдерживает стоимости привлечения |
| Деньги | Заказы × Δчек × оплата × выкуп |
| Плейбуки | PB-13, PB-42, PB-15 |

### 05 · Высокие возвраты и отказы

| Звено | Содержание |
| --- | --- |
| Симптом | Значительная часть заказов не доходит до выручки |
| Корневые причины | Ожидание не совпало с товаром · логистика · импульсный заказ без подтверждения |
| Вторичные | Фото не соответствуют товару · нет размерной подсказки · долгая доставка · заказ в один клик без прогрева |
| Бизнес-эффект | Себестоимость растёт дважды: логистика туда и обратно плюс упавший товар |
| Деньги | Заказы × Δвыкуп × чек |
| Плейбуки | PB-20, PB-19, PB-15 |

### 06 · Нет органического трафика

| Звено | Содержание |
| --- | --- |
| Симптом | Доля небрендовой органики мала |
| Корневые причины | Структура сайта не совпадает со структурой спроса · технические барьеры · нет контента под интент |
| Вторичные | Нет посадок под уточнённый спрос · дубли · мета не по локали · медленная загрузка |
| Бизнес-эффект | Каждый заказ куплен; актив не накапливается |
| Деньги | Прогноз трафика по кластерам × CR × чек |
| Плейбуки | PB-04, PB-05, PB-07, PB-06 |

### 07 · Убыточные заказы

| Звено | Содержание |
| --- | --- |
| Симптом | CM3 отрицательна на части заказов |
| Корневые причины | Цена не покрывает полную себестоимость · промо глубже маржи · логистика недооценена |
| Вторичные | Себестоимость не считается по SKU · бесплатная доставка ниже порога окупаемости · возвраты не в себестоимости |
| Бизнес-эффект | Рост оборота увеличивает убыток |
| Деньги | Доля убыточных заказов × средний убыток на заказ |
| Плейбуки | PB-12, PB-13, PB-33 |

**Блокирующий узел.** Пока он открыт, масштабирование любого канала усиливает потери.

### 08 · Данные не сходятся

| Звено | Содержание |
| --- | --- |
| Симптом | Аналитика и бэкенд расходятся |
| Корневые причины | Событийная модель неполна · дубли событий · нет серверного трекинга |
| Вторичные | Нет словаря метрик · разметка ставится вручную · атрибуция не зафиксирована |
| Бизнес-эффект | Все решения принимаются по неверным цифрам |
| Деньги | Не считаются напрямую; узел блокирует расчёт остальных |
| Плейбуки | PB-10, PB-11 |

**Блокирующий узел.** Первая волна независимо от ранга.

### 09 · Зависимость от одного канала

| Звено | Содержание |
| --- | --- |
| Симптом | Доля крупнейшего канала выше 70% |
| Корневые причины | Другие каналы не тестировались · нет ресурса на развитие · органика и бренд не строились |
| Бизнес-эффект | Хрупкость: изменение алгоритма или политики площадки обрушивает выручку. Снижает оценку компании при продаже |
| Деньги | Стоимость риска: доля канала × выручка × вероятность потери |
| Плейбуки | PB-03, PB-41, PB-04 |

### 10 · Цена вне контроля

| Звено | Содержание |
| --- | --- |
| Симптом | Один товар продаётся по разным ценам в разных каналах |
| Корневые причины | **Производитель:** нет RRP и контроля реселлеров. **Реселлер:** дистрибьютор торгует напрямую |
| Вторичные | Нет собственных кабинетов на площадках · нет договорной дисциплины · нет мониторинга |
| Бизнес-эффект | Конверсия сайта падает, маржа размывается, премиальность разрушается |
| Деньги | Отклонение цены × объём, уходящий в чужие каналы |
| Плейбуки | PB-13, PB-21, PB-37 |

### 11 · Ассортимент растёт, выручка нет

| Звено | Содержание |
| --- | --- |
| Симптом | Число SKU выросло, оборот на месте |
| Корневые причины | Коллекция формируется под производство, а не под спрос · нет ABC-дисциплины |
| Вторичные | Новинки не получают трафика · неликвид не выводится · товарные данные неконсистентны |
| Бизнес-эффект | Оборотный капитал заморожен, операции нагружены, витрина размыта |
| Деньги | Замороженный капитал × стоимость денег + упущенная оборачиваемость |
| Плейбуки | PB-28, PB-42, PB-29 |

### 12 · Бренда нет как актива

| Звено | Содержание |
| --- | --- |
| Симптом | Малая доля прямого трафика, нет брендового спроса |
| Корневые причины | Позиционирование не сформулировано · дифференциатор есть, но не заявлен · нет коммуникации за пределами продажи |
| Бизнес-эффект | Конкуренция только ценой; CAC не снижается со временем |
| Деньги | Разница между CAC платного и прямого трафика × объём |
| Плейбуки | PB-37, PB-46, PB-50 |

## Как пользоваться при разборе

1. Взять симптом из таблицы аудита.
2. Найти узел. Спуститься до корневых причин.
3. Проверить каждую по данным — какие подтверждаются.
4. Разделить вклад, если причин несколько.
5. Плейбук получает **корневая причина**, не симптом.
6. Деньги считаются один раз на узел, а не на каждую причину.

**Частая ошибка.** Взять симптом «низкий LTV» и назначить PB-08. Если клиент не
принадлежит бренду, потому что продажи идут через площадку, retention-контур строить
не на ком — сначала PB-21, забрать клиента в собственную базу.
