## Дисциплина честности

Данные конкурентов берутся из открытых источников — сайты, кабинеты маркетплейсов,
соцсети, инструменты видимости — и потому **неполны и приблизительны**. Оценки по
шкале 1–5 экспертные и субъективные. Это указывается в отчёте прямо: конкурентный
блок показывает направление и порядок величин, а не измеренный факт.

Отдельный обязательный шаг: проверить, **не занимают ли выдачу реселлеры самого
клиента**. Для производителя это часто более значимый конкурент, чем профильные
ретейлеры.

**Правило вердикта:**

| Позиция | Условие |
| --- | --- |
| 🟢 Лидер | Клиент не хуже лучшего конкурента по параметру |
| 🟡 Паритет | Клиент в пределах ~10% от лучшего конкурента |
| 🔴 Отставание | Клиент заметно уступает — приоритет и/или зона дифференциации |
| — Справка | Параметр без вердикта: дешевле не значит лучше |

Цена помечена как контекстная намеренно. Более низкая цена — не преимущество, пока
не подтверждена юнит-экономикой.

## Блок 2 · Индекс конкурентоспособности

Оценка 1–5 по десяти ключевым параметрам с весами. Индекс каждого игрока —
взвешенное среднее, приведённое к шкале 0–5.

| Параметр | Вес |
| --- | --- |
| Ценность и дифференциация | 3 |
| SEO-видимость | 3 |
| Retention и лояльность | 3 |
| Сила бренда | 3 |
| Контент и карточка | 2 |
| Скорость и UX | 2 |
| Каналы привлечения | 2 |
| Присутствие на МП | 2 |
| Репутация, отзывы | 2 |
| Логистика и доставка | 1 |

```
Индекс = Σ(оценка × вес) / Σ(вес) × (5 / 5)
Ранг клиента — место среди всех игроков, 1 = лидер рынка
```

Веса не универсальны: для категории с редкой покупкой вес retention снижается, для
FMCG — растёт. Пересматривай их под нишу до заполнения, а не после.

## Блок 3 · Карта позиционирования

Две оси, оценка игроков 0–10 по каждой. По умолчанию: **X — цена от низкой к
высокой, Y — специализация и ценность**. Оси можно менять под категорию, но обе
должны быть значимы для выбора покупателя.

Квадрант, где нет ни одного сильного игрока, — незанятая ценная позиция. Это
кандидат в дифференциацию бренда (PB-37) и основа для позиционирования (PB-46).

**Проверка перед выводом.** Пустой квадрант бывает пустым по двум причинам: там нет
спроса, либо туда никто не дошёл. Прежде чем называть его white space, ответь, какой
покупатель туда пойдёт и почему его до сих пор не обслужили.
