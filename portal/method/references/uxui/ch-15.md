# Глава 15. Search Experience (Site Search)

## 15.1 Роль поиска в eCommerce
Поиск является не дополнительной функцией интернет-магазина, а самостоятельной системой навигации, предназначенной для пользователей с высокой покупательской готовностью.
Практически во всех крупных eCommerce-проектах пользователи, использующие поиск, демонстрируют:
более высокую конверсию;
более высокий средний чек;
меньшее количество отказов;
более короткий путь до покупки.
Поиск должен проектироваться как отдельный цифровой продукт со своей архитектурой, алгоритмами ранжирования, аналитикой и системой оптимизации.

## 15.2 Цели поиска
Система поиска должна обеспечивать:
быстрое нахождение товара;
корректную интерпретацию запроса;
устойчивость к ошибкам пользователя;
поддержку естественного языка;
высокую релевантность результатов;
персонализацию выдачи;
поддержку коммерческих сценариев.

## 15.3 Архитектура поиска
Современная поисковая система состоит из нескольких независимых модулей.
Пользователь
↓
Обработка запроса
↓
Нормализация
↓
Исправление ошибок
↓
Поиск совпадений
↓
Ранжирование
↓
Бизнес-правила
↓
Персонализация
↓
Формирование выдачи
Каждый этап должен иметь собственные правила настройки и аналитики.

## 15.4 Типы поисковых запросов

### Exact Match
Полное совпадение.
Пример:
MacBook Air M4

### Partial Match
Частичное совпадение.
Пример:
MacBook

### Attribute Search
Поиск по характеристикам.
Пример:
16 GB RAM

### Brand Search
Поиск бренда.
Пример:
Bosch

### Category Search
Поиск категории.
Пример:
Шуруповерт

### Problem Search
Поиск решения задачи.
Пример:
Подарок мужчине
↓
Не товар.
А задача.

### Natural Language Search
Например.
“Ноутбук для работы до 50000 грн”
Современные AI-поисковые системы должны понимать подобные запросы.

## 15.5 Search Pipeline
Каждый запрос проходит несколько стадий обработки.

### Нормализация
Например.
APPLE
↓
Apple
↓
apple

### Морфология
Ноутбук
↓
Ноутбуки
↓
Ноутбука
↓
Ноутбуков

### Исправление опечаток
Samzung
↓
Samsung

### Синонимы
Телевизор
↓
TV
↓
Smart TV

### Транслитерация
macbuk
↓
MacBook

### Раскладка клавиатуры
vf,er
↓
MacBook

## 15.6 Autocomplete
Автодополнение должно начинать работать после ввода первых символов.
Рекомендуемый состав.
Поисковые запросы.
Категории.
Товары.
Бренды.
Популярные запросы.
История поиска.
Подсказки.
Автодополнение должно сокращать количество вводимых символов.

## 15.7 Search Suggestions
Подсказки могут формироваться на основе:
популярности;
сезонности;
истории пользователя;
остатков;
маржинальности;
аналитики.
Например.
Пользователь вводит
iPh
↓
iPhone 16
↓
iPhone 16 Pro
↓
iPhone 16 Pro Max

## 15.8 Search Results Page
Страница результатов поиска должна содержать:
поисковую строку;
количество найденных товаров;
сортировку;
фильтрацию;
карточки товаров;
исправление ошибок;
альтернативные запросы;
пагинацию;
рекомендации.

## 15.9 Zero Results
Отсутствие результатов не должно приводить к тупику.
Вместо сообщения
“Ничего не найдено”
необходимо предложить:
исправленный запрос;
похожие товары;
категории;
популярные товары;
помощь консультанта;
очистку фильтра;
рекомендации.
Zero Results также являются ценным источником аналитики.

## 15.10 Ranking
Ранжирование должно учитывать множество факторов.
Например.
Текстовое соответствие.
↓
Популярность.
↓
Конверсия.
↓
Наличие.
↓
Маржинальность.
↓
Рейтинг.
↓
Количество отзывов.
↓
Персонализация.
↓
Бизнес-правила.
Поиск не должен ранжировать результаты исключительно по совпадению текста.

## 15.11 Searchandising
Searchandising — управление поисковой выдачей с учетом коммерческих целей.
Используется для:
новинок;
акций;
высокомаржинальных товаров;
собственных брендов;
распродажи остатков.
Важно соблюдать баланс между коммерческой выгодой и релевантностью.
Нерелевантная выдача быстро снижает доверие пользователей.

## 15.12 Персонализация поиска
Поисковая выдача может учитывать:
историю просмотров;
историю покупок;
регион;
язык;
устройство;
ценовой сегмент;
интересы пользователя.
Персонализация должна улучшать релевантность, но не скрывать важные альтернативы.

## 15.13 AI Search
Современные поисковые системы используют AI для понимания намерения пользователя.
Например.
Запрос:
“Плед в подарок маме”
↓
AI определяет:
повод;
целевую аудиторию;
ценовой сегмент;
стиль;
материал.
↓
Формирует персонализированную выдачу.
AI также может использоваться для:
семантического поиска;
векторного поиска;
визуального поиска;
голосового поиска;
диалогового поиска.

## 15.14 Визуальный поиск
Пользователь загружает изображение.
↓
Система находит похожие товары.
Особенно эффективно для:
одежды;
мебели;
декора;
аксессуаров;
предметов интерьера.

## 15.15 Голосовой поиск
При проектировании необходимо учитывать особенности разговорных запросов.
Например.
“Покажи беспроводные наушники Sony до пяти тысяч гривен.”
↓
Поиск должен корректно интерпретировать все параметры запроса.

## 15.16 Search Analytics
Поиск является одним из наиболее ценных источников данных о пользователях.
Необходимо анализировать:
самые популярные запросы;
нулевые результаты;
частоту использования поиска;
CTR результатов;
конверсию после поиска;
время до покупки;
частоту уточнения запросов;
использование подсказок.

## 15.17 Search KPI
Рекомендуется отслеживать следующие показатели.
Search Usage Rate.
Search Exit Rate.
Search Conversion Rate.
Zero Result Rate.
Average Query Length.
Search CTR.
Search Success Rate.
Search Refinement Rate.
Search-to-Purchase Rate.
Average Revenue per Search.

## 15.18 Типичные ошибки
Использование простого текстового поиска.
Отсутствие морфологии.
Отсутствие исправления ошибок.
Игнорирование синонимов.
Плохое ранжирование.
Невозможность поиска по артикулу.
Игнорирование поиска по характеристикам.
Плохая мобильная версия.
Отсутствие аналитики поиска.
Игнорирование Zero Results.
Отсутствие Searchandising.
Отсутствие AI-поиска.

## 15.19 Deliverables
По результатам проектирования должны быть подготовлены:
Search Experience Specification;
Search Architecture Diagram;
Query Processing Rules;
Synonym Dictionary;
Typo Dictionary;
Search Ranking Model;
Searchandising Rules;
Zero Results Strategy;
AI Search Specification;
Search Analytics Dashboard;
Search KPI Matrix;
Search QA Checklist.
