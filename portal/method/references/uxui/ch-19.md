# Глава 19. Typography System

## 19.1 Роль типографики в UX
Типографика — это система организации текстовой информации, обеспечивающая быстрое восприятие, понимание и принятие решений пользователем.
В интерфейсах eCommerce текст является основным носителем информации. Именно через текст пользователь получает сведения о товаре, условиях покупки, доставке, гарантии, наличии, цене и характеристиках.
Качественная типографическая система должна:
сокращать время поиска информации;
уменьшать когнитивную нагрузку;
облегчать сканирование страницы;
повышать читаемость;
поддерживать визуальную иерархию;
обеспечивать единообразие интерфейса.
Типографика является функциональным инструментом, а не декоративным элементом.

## 19.2 Принципы типографической системы
Типографическая система должна строиться на пяти фундаментальных принципах.

### Иерархия
Каждый уровень информации должен визуально отличаться.
Пользователь должен понимать приоритет информации без чтения всего текста.

### Последовательность
Все страницы используют одинаковые размеры, интервалы и стили.
Одинаковые сущности оформляются одинаково.

### Читаемость
Текст должен легко восприниматься при любых размерах экрана.

### Контраст
Необходимо обеспечить достаточную разницу между уровнями информации.

### Масштабируемость
Типографическая система должна работать:
Desktop;
Tablet;
Mobile;
Large Display.

## 19.3 Типографическая шкала
Рекомендуется использовать модульную шкалу.
Например.

| Стиль | Размер |
| --- | --- |
| Display XL | 64 px |
| Display L | 56 px |
| H1 | 48 px |
| H2 | 40 px |
| H3 | 32 px |
| H4 | 28 px |
| H5 | 24 px |
| H6 | 20 px |
| Body L | 18 px |
| Body | 16 px |
| Body S | 14 px |
| Caption | 12 px |
| Overline | 11 px |

Размеры являются частью Design Tokens и не должны задаваться произвольно.

## 19.4 Типографические роли
Каждый стиль имеет фиксированное назначение.

### Display
Используется:
Hero;
Landing;
рекламные баннеры.

### Heading
Используется:
заголовки страниц;
названия блоков.

### Body
Используется:
описания;
статьи;
характеристики;
инструкции.

### Label
Используется:
кнопки;
поля ввода;
формы;
фильтры.

### Caption
Используется:
подписи;
вспомогательная информация;
даты;
артикулы.

## 19.5 Вертикальный ритм
Вертикальный ритм определяет расстояния между строками, абзацами и блоками текста.
Правила:
Заголовок всегда ближе к связанному с ним контенту, чем к предыдущему блоку.
Абзацы отделяются интервалами, а не пустыми строками.
Межстрочный интервал должен обеспечивать комфортное чтение.
Нарушение вертикального ритма делает интерфейс визуально хаотичным.

## 19.6 Длина строки
Слишком длинные строки снижают скорость чтения.
Рекомендуемые значения.
Desktop.
60–90 символов.
Mobile.
30–45 символов.
Для карточек товара рекомендуется использовать ещё более короткие строки.

## 19.7 Межстрочный интервал
Рекомендуемый Line Height.
Заголовки.
110–130%.
Основной текст.
140–170%.
Инструкции.
150–180%.
Таблицы.
120–140%.

## 19.8 Типографика карточки товара
Карточка товара требует собственной системы.
Приоритет.
Название товара.
↓
Цена.
↓
Скидка.
↓
CTA.
↓
Основные преимущества.
↓
Характеристики.
↓
Описание.
↓
Дополнительная информация.
Название товара не должно конкурировать с ценой.
Цена не должна конкурировать с CTA.

## 19.9 Типографика каталога
Карточка товара в каталоге должна содержать минимальный объём текста.
Основные элементы.
Название.
Цена.
Рейтинг.
Наличие.
Badge.
CTA.
Любая дополнительная информация ухудшает скорость сканирования каталога.

## 19.10 Типографика Checkout
Checkout требует максимальной ясности.
Приоритет.
Название этапа.
↓
Основные поля.
↓
Ошибки.
↓
Подсказки.
↓
Кнопка подтверждения.
Ошибки должны быть заметны сразу после возникновения.

## 19.11 Типографика форм
Каждое поле должно иметь:
Label;
Placeholder (не вместо Label);
Helper Text;
Error Message;
Success Message.
Placeholder не может использоваться как единственный способ обозначения назначения поля.

## 19.12 Типографика ошибок
Сообщение об ошибке должно отвечать на три вопроса:
Что произошло?
Почему это произошло?
Что необходимо сделать?
Пример.
❌ Неправильно.
Ошибка.
✅ Правильно.
Не удалось выполнить оплату.
Проверьте данные карты или выберите другой способ оплаты.

## 19.13 Локализация
Типографическая система должна учитывать:
различные языки;
длину слов;
направление письма (LTR/RTL);
особенности чисел;
валюты;
единицы измерения.
Компоненты должны выдерживать увеличение длины текста без нарушения композиции.

## 19.14 Адаптивная типографика
Размеры текста не должны масштабироваться линейно.
Для мобильных устройств допускается уменьшение размеров, но сохраняется визуальная иерархия.
Проверяются:
переносы строк;
обрезка текста;
переполнение;
масштабирование при системных настройках.

## 19.15 Variable Fonts
Для современных проектов рекомендуется использовать Variable Fonts.
Преимущества:
уменьшение количества файлов;
плавное изменение насыщенности;
улучшение производительности;
гибкость адаптации.

## 19.16 Accessibility
Типографика должна соответствовать требованиям доступности.
Проверяется:
минимальный размер текста;
контраст;
масштабирование до 200%;
читаемость без потери функциональности;
поддержка экранных дикторов.
Недопустимо использовать изображение вместо текста там, где необходима машинная интерпретация.

## 19.17 Типичные ошибки
Использование более трёх гарнитур.
Случайные размеры текста.
Отсутствие типографической шкалы.
Использование Placeholder вместо Label.
Слишком маленький текст.
Недостаточный контраст.
Слишком длинные строки.
Слишком плотный межстрочный интервал.
Отсутствие адаптации под мобильные устройства.
Нарушение визуальной иерархии.

## 19.18 Typography QA Checklist
Перед выпуском интерфейса необходимо проверить:
соблюдение типографической шкалы;
корректность ролей текста;
читаемость на всех разрешениях;
соответствие Design Tokens;
отсутствие произвольных размеров;
соответствие Accessibility;
корректность локализации;
отсутствие переполнений и обрезки текста.

## 19.19 Deliverables
По итогам разработки типографической системы должны быть подготовлены:
