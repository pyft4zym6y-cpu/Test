# Глава 59. Enterprise UX/UI Pattern Encyclopedia

## 59.1 Назначение энциклопедии паттернов
Если Playbook объясняет как проектировать, а Pattern Library показывает что использовать, то Pattern Encyclopedia отвечает на вопрос:
Какие решения существуют вообще?
Это не каталог компонентов.
Это база знаний обо всех известных UX/UI решениях.
В итоговой версии энциклопедия должна содержать 3000–5000 паттернов.

## 59.18 Pattern Evaluation Matrix
Каждый паттерн оценивается.

| Критерий | Описание |
| --- | --- |
| UX Impact | Влияние на UX |
| Conversion Impact | Влияние на конверсию |
| Complexity | Сложность реализации |
| Development Cost | Стоимость разработки |
| Maintenance | Стоимость сопровождения |
| Accessibility | Совместимость с WCAG |
| Performance | Влияние на производительность |
| Scalability | Масштабируемость |
| Mobile Suitability | Подходит ли для Mobile |
| Enterprise Readiness | Готовность для Enterprise |


## 59.19 Anti-Patterns Encyclopedia
Для каждого паттерна фиксируются распространённые ошибки.
Например.
Sticky Header.
Ошибки.
слишком высокий;
закрывает контент;
перекрывает фильтры;
конфликтует с поиском;
не адаптирован под Mobile;
вызывает CLS.

### Следующая глава
Глава 60. Enterprise Anti-Patterns Encyclopedia станет противоположностью библиотеки лучших практик. Она систематизирует 1500+ наиболее распространённых UX/UI, CRO, Product, IA, Navigation, Checkout, Mobile, Performance и AI-ошибок, объяснит причины их появления, влияние на конверсию и предложит способы исправления. Такая энциклопедия станет незаменимым инструментом для UX-аудитов и Design Review.
