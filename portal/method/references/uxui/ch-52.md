# Глава 52. Enterprise Component Library & Screen Templates

## 52.1 Назначение библиотеки компонентов
Design System определяет правила.
Component Library предоставляет готовые строительные блоки.
Screen Templates показывают, как компоненты объединяются в реальные интерфейсы.
Цель библиотеки:
сократить время проектирования;
ускорить разработку;
уменьшить количество UI-ошибок;
обеспечить единообразие интерфейсов;
снизить стоимость сопровождения.

## 52.26 Типичные ошибки
Создание новых компонентов вместо повторного использования.
Изменение существующих компонентов без обновления библиотеки.
Отсутствие документации.
Несогласованность между Figma и кодом.
Дублирование экранов.
Разные версии одного компонента.
Игнорирование Accessibility.
Отсутствие аналитики.

## 52.27 QA Checklist
Перед публикацией необходимо проверить:
компонент соответствует Design System;
все состояния реализованы;
компонент адаптивен;
поддерживает Accessibility;
аналитика настроена;
существует кодовая реализация;
документация актуальна;
добавлены примеры использования;
шаблоны экранов используют только утверждённые компоненты;
компонент прошёл Design Review и QA.
