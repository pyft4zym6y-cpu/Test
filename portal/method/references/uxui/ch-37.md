# Глава 37. eCommerce Analytics & Digital Measurement Framework

## 37.1 Analytics как основа управления eCommerce
Современный eCommerce невозможно эффективно развивать без системы измерения.
Любое изменение интерфейса, маркетинга, ассортимента или бизнес-процессов должно оцениваться через данные.
Analytics — это не отчёты.
Analytics — это система принятия решений.
Главная задача аналитики — ответить на вопросы:
Что происходит?
Почему это происходит?
Что изменилось?
Что делать дальше?
Какое решение принесёт максимальный эффект?

## 37.3 Measurement Framework
До настройки аналитики определяется Measurement Framework.
Он отвечает на вопросы.
Что измеряем?
↓
Почему измеряем?
↓
Как измеряем?
↓
Какие KPI изменятся?
↓
Какие решения будут приниматься?
Настройка аналитики без Measurement Framework приводит к накоплению большого количества бесполезных событий.

## 37.6 Event Taxonomy
Каждое событие должно иметь единый стандарт именования.
Например.

Product View

## 37.26 Типичные ошибки
Настройка аналитики без Measurement Framework.
Отсутствие единой Event Taxonomy.
Разные названия одинаковых событий.
Избыточное количество событий без бизнес-ценности.
Отсутствие Data Layer.
Отсутствие QA трекинга.
Использование нескольких источников правды.
Отсутствие BI.
Невозможность связать маркетинг, UX и продажи.
Игнорирование Server-Side Tracking.

## 37.27 Analytics Maturity Model

| Уровень | Характеристика |
| --- | --- |
| Level 1 | Базовые отчёты (GA4 без стандартизации событий) |
| Level 2 | Стандартизированная Event Taxonomy, единый Data Layer |
| Level 3 | Интеграция с Data Warehouse, BI и сквозной аналитикой |
| Level 4 | Data-Driven управление, автоматические алерты, когортный анализ, атрибуция |
| Level 5 | AI-аналитика, прогнозирование, автоматические рекомендации, Self-Service BI, Near Real-Time Dashboard |
