# Глава 33. Filtering, Sorting & Faceted Search

## 33.1 Роль фильтрации в eCommerce
Система фильтрации является одним из ключевых механизмов поиска товаров.
Если поиск отвечает на вопрос:
“Что именно я хочу найти?”
то фильтрация отвечает на вопрос:
“Как быстро сузить тысячи товаров до нескольких подходящих?”
Для каталогов, содержащих более нескольких сотен SKU, отсутствие качественной системы фильтрации практически гарантированно приводит к снижению конверсии.
Правильно спроектированная система фильтрации должна:
уменьшать когнитивную нагрузку;
сокращать время поиска;
уменьшать количество просмотров ненужных товаров;
увеличивать вероятность покупки;
повышать удовлетворённость пользователя.

## 33.2 Архитектура Faceted Search
Современная система фильтрации строится по модели Faceted Navigation.
Каждый товар описывается множеством независимых атрибутов.
Например.
Категория
↓
Бренд
↓
Цена
↓
Размер
↓
Материал
↓
Цвет
↓
Вес
↓
Рейтинг
↓
Наличие
↓
Скидка
Каждый фильтр является независимой характеристикой товара.

## 33.4 Принципы проектирования фильтров
Фильтры должны быть:
понятными;
предсказуемыми;
быстрыми;
независимыми;
масштабируемыми;
релевантными категории.
Не допускается отображение фильтров, не имеющих смысла для текущей категории.

## 33.5 Типы фильтров

### Single Select
Выбор одного значения.
Например.
Пол.
↓
Мужской
↓
Женский
↓
Унисекс

### Multi Select
Допускается несколько вариантов.
Например.
Цвет.
Черный.
Белый.
Синий.

### Range
Диапазон.
Например.
Цена.
1000–5000 грн.

### Boolean
Да / Нет.
Например.
В наличии.
Новинка.
Со скидкой.
Бесплатная доставка.

### Rating
Например.
★★★★☆
и выше.

### Hierarchical
Иерархические фильтры.
Например.
Инструмент
↓
Шлифмашины
↓
Ленточные

## 33.7 Dependent Filters
Некоторые фильтры зависят друг от друга.
Например.
Бренд.
↓
Apple
↓
Показываются только модели Apple.
Не следует отображать невозможные комбинации.

## 33.9 Price Filter
Фильтр цены рекомендуется реализовывать через:
ползунок;
ручной ввод;
предустановленные диапазоны.
Например.
До 1000 грн.
1000–3000 грн.
3000–5000 грн.
Более 5000 грн.

## 33.10 Color Filter
Лучше использовать:
цветовые образцы (Swatches);
подписи;
комбинированный вариант.
Не рекомендуется использовать только текст.

## 33.11 Size Filter

Например.

M.
L.
XL.
или
41.
42.
43.
44.

## 33.12 Availability Filter

Под заказ.
Предзаказ.
Со склада.
Бесплатная доставка.

## 33.13 Active Filters
После выбора фильтров пользователь должен видеть все активные ограничения.
Например.
Samsung
×
До 10000 грн
×
★★★★★
×
Черный
×
Каждый фильтр должен удаляться одним действием.

## 33.14 Clear Filters
Необходимо предусмотреть:
Сброс одного фильтра.
↓
Сброс группы.
↓
Сброс всех фильтров.

## 33.15 Mobile Filters
На мобильных устройствах рекомендуется использовать Bottom Sheet.
Содержит.
Фильтры.
↓
Количество найденных товаров.
↓
Применить.
↓
Очистить.
Пользователь должен понимать результат ещё до применения фильтра.

## 33.16 Instant Filtering
После изменения фильтра возможны два подхода.
Автоматическое обновление.
или
Кнопка
Применить.
Выбор зависит от:
размера каталога;
скорости поиска;
нагрузки.

## 33.18 Faceted SEO
Не каждая комбинация фильтров должна индексироваться.
Необходимо определить:
индексируемые комбинации;
канонические URL;
закрытые параметры;
динамические страницы.
Это позволяет избежать большого количества дублирующихся страниц.

## 33.19 Производительность
Фильтрация должна работать практически мгновенно.
Рекомендуемые требования.
Время применения фильтра — минимально возможное.
Изменение результатов не должно сопровождаться полной перезагрузкой страницы.
Необходимо минимизировать Layout Shift.

## 33.20 Analytics

Filter Open;
Filter Usage;
Filter Remove;
Clear Filters;
Sort Change;
Price Filter Usage;
Search After Filter;
Zero Results;

## 33.21 KPI Filtering

| KPI | Назначение |
| --- | --- |
| Filter Usage Rate | Использование фильтров |
| Average Filters per Session | Среднее число применённых фильтров |
| Zero Result Rate | Комбинации без результатов |
| Filter-to-PDP Rate | Переходы в карточку после фильтрации |
| Time to Product | Время до выбора товара |
| Sort Usage Rate | Использование сортировки |
| Filter Reset Rate | Частота сброса фильтров |
| Conversion After Filtering | Конверсия пользователей, применивших фильтры |


## 33.22 Типичные ошибки
Отображение нерелевантных фильтров.
Слишком длинный список фильтров без группировки.
Полная перезагрузка страницы после каждого изменения.
Отсутствие отображения активных фильтров.
Невозможность быстро очистить фильтры.
Несогласованность фильтрации и сортировки.
Появление комбинаций, не дающих результатов, без предупреждения.
Использование только текстового представления цветов.
Отсутствие мобильной оптимизации.
Игнорирование SEO-последствий Faceted Navigation.

## 33.23 Filtering QA Checklist
Перед запуском необходимо проверить:
фильтры соответствуют категории;
зависимые фильтры работают корректно;
активные фильтры отображаются явно;
пользователь может быстро очистить один или все фильтры;
сортировка не конфликтует с фильтрацией;
мобильный интерфейс удобен для управления одной рукой;
изменения применяются без полной перезагрузки страницы;
аналитика настроена;
требования Accessibility соблюдены;
SEO-правила для Faceted Navigation реализованы.
