# Глава 7. Customer Journey Map (CJM)

## 7.1 Назначение Customer Journey Map
Customer Journey Map (CJM) — это модель полного пути клиента от момента возникновения потребности до повторной покупки и формирования долгосрочных отношений с брендом.
В отличие от User Flow, который описывает взаимодействие с интерфейсом, CJM рассматривает весь клиентский опыт, включая точки контакта, эмоции, ожидания, барьеры и процессы, происходящие вне сайта.
Цель CJM — выявить причины, по которым пользователь прекращает движение к покупке, и определить возможности для улучшения пользовательского опыта.

## 7.2 Основные отличия CJM

| Инструмент | Что описывает |
| --- | --- |
| Persona | Кто пользователь |
| JTBD | Какую задачу он пытается решить |
| User Flow | Как пользователь взаимодействует с интерфейсом |
| Task Flow | Последовательность выполнения одной задачи |
| Customer Journey Map | Полный жизненный цикл клиента |


## 7.3 Принципы построения CJM
Customer Journey строится вокруг действий пользователя, а не процессов компании.
Нельзя начинать карту с момента открытия сайта.
Путь клиента начинается значительно раньше.
Например:
Возникла проблема
↓
Осознание потребности
↓
Поиск вариантов
↓
Сравнение магазинов
↓
Первое посещение сайта
↓
Выбор товара
↓
Покупка
↓
Получение заказа
↓
Использование товара
↓
Повторная покупка
↓
Рекомендация другим пользователям

## 7.4 Этапы Customer Journey

### Stage 1. Awareness

#### Цель пользователя
Понять, что существует проблема.

#### Основные вопросы

#### UX-задачи бизнеса

### Stage 2. Consideration
Пользователь начинает изучать рынок.

#### Действия
Изучает конкурентов.
Сравнивает цены.
Смотрит обзоры.
Читает отзывы.

#### Основные вопросы
Какой вариант лучше?
Можно ли доверять?
Почему цена отличается?

#### UX-задачи
Максимально подробно ответить на возникающие вопросы.

### Stage 3. Evaluation
Пользователь сравнивает конкретные товары.
Основные действия
Фильтрация.
Поиск.
Сравнение.
Отзывы.
Видео.
Характеристики.
Наиболее важные элементы UX
Поиск.
Фильтры.
Карточка товара.
Сравнение.
FAQ.

### Stage 4. Purchase
Самый короткий, но наиболее чувствительный этап.
Основная задача пользователя —
максимально быстро завершить покупку.
UX должен обеспечить:
минимальное количество шагов;
отсутствие неожиданностей;
понятную стоимость доставки;
понятные способы оплаты;
простое заполнение форм.

### Stage 5. Delivery
После оплаты пользователь продолжает взаимодействовать с компанией.
UX распространяется на:
уведомления;
отслеживание заказа;
изменение адреса;
контакт с поддержкой.

### Stage 6. Usage
Пользователь начинает использовать товар.
На этом этапе формируется удовлетворённость покупкой.
Компания должна обеспечить:
инструкции;
FAQ;
поддержку;
обучающие материалы;
контент.

### Stage 7. Loyalty
Формируются повторные покупки.
Используются:
персонализация;
рекомендации;
бонусная программа;
email-маркетинг;
мобильное приложение.

### Stage 8. Advocacy
Пользователь становится адвокатом бренда.
Формируется:
повторное взаимодействие;
отзывы;
UGC;
реферальная программа;
социальные рекомендации.

## 7.5 Структура CJM
Каждая карта должна содержать одинаковый набор элементов.

### Этап
Например:
Поиск товара.

### Цель пользователя
Что пользователь пытается сделать?

### Действия
Что делает пользователь?

### Мысли
О чём думает пользователь?

### Эмоции
Что чувствует пользователь?

### Pain Points
Что вызывает проблемы?

### Touchpoints
Какие каналы используются?
Например:
Google.
Instagram.
Email.
Сайт.
Поддержка.
Телефон.
Мобильное приложение.

### Opportunities
Что можно улучшить?

## 7.8 Opportunity Mapping
После анализа проблем строится карта возможностей.
Каждая возможность оценивается по нескольким параметрам.
Влияние на пользователя.
Влияние на бизнес.
Стоимость реализации.
Сложность.
Время внедрения.
Приоритет.

## 7.11 Типичные ошибки
Построение CJM только внутри сайта.
Игнорирование этапа до первого посещения сайта.
Игнорирование этапа после покупки.
Отсутствие эмоциональной оценки.
Описание процессов компании вместо действий пользователя.
Построение одной карты для всех сегментов.
Отсутствие количественных метрик.

## 7.12 Deliverables
По результатам разработки Customer Journey Map должны быть подготовлены следующие артефакты:
Customer Journey Map;
Touchpoint Inventory;
Emotional Journey Map;
Pain Point Register;
Opportunity Map;
Service Blueprint (при необходимости);
Customer Experience Backlog;
UX Improvement Roadmap;
Prioritization Matrix;
Journey KPI Dashboard.
Эти материалы используются как входные данные для следующих глав Playbook: Experience Map, User Flow, Task Flow, Information Architecture, а также для проектирования страниц интернет-магазина и омниканального клиентского опыта.
