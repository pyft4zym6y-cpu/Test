## DOMAIN 12 — NAVIGATION QUALITY

Registry v1.0
Цель домена: определить, насколько эффективно навигационная система помогает пользователю достигать целей с минимальными затратами времени, усилий и когнитивной нагрузки.

Definition
Навигация —
это не меню.
Навигация —
это система принятия решений о перемещении.
Хорошая навигация делает путь очевидным.
Плохая навигация заставляет пользователя думать.

Navigation Failure Taxonomy
Все нарушения относятся к одной из категорий:
Orientation Failure — пользователь не понимает, где находится.
Hierarchy Failure — структура меню противоречит информационной архитектуре.
Navigation Dead End — отсутствует путь продолжения или возврата.
Label Failure — названия разделов не соответствуют ожиданиям.
Depth Failure — слишком много уровней вложенности.
Breadth Failure — чрезмерное количество вариантов выбора на одном уровне.
Context Loss — пользователь теряет понимание своего положения после переходов.
Search Dependency — навигация настолько слаба, что поиск становится единственным способом найти информацию.
AI Navigation Failure — AI рекомендует маршруты, ухудшающие ориентирование или не соответствующие намерению пользователя.

Этот домен завершает архитектурный слой оценки перемещения пользователя по продукту. Следующим логическим доменом станет Forms & Data Entry, посвящённый глубокой оценке ввода данных, ошибок, валидации, автозаполнения, прогрессивного раскрытия полей и оптимизации когнитивной нагрузки в формах. Он станет одним из самых объёмных доменов, поскольку формы являются ключевой точкой конверсии практически во всех цифровых продуктах.
