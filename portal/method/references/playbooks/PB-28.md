# PB-28 · ABC/XYZ и чистка ассортимента

| Домен | Продукт / Ассортимент |
| --- | --- |
| Срабатывает по правилам | R42 |
| Вопросы-источники | PD-001…PD-006, PX-027, FI-105 |
| Длительность | 3 недели |

### 1  Зачем нужен этот плейбук
Каталог, который бесконтрольно растёт, накапливает неликвид: позиции, которые не продаются, замораживают деньги, засоряют выдачу и портят восприятие ассортимента. ABC/XYZ-анализ наводит порядок: классифицирует товары по вкладу и стабильности спроса и даёт основание для чистки.
Плейбук классифицирует ассортимент по выручке и предсказуемости спроса, накладывает маржинальность и формирует план: что развивать, что репрайсить, что выводить.

|  | Корневая проблема Ассортимент разросся без управления. Высокая доля неликвида замораживает оборотный капитал, слабые SKU портят восприятие и разбавляют каталог, а часть позиций убыточна. Решения о вводе и выводе принимаются интуитивно. |
| --- | --- |

### 3  Что нужно на входе
Полный список требований к данным и доступам — в документе «Реестр данных и доступов». Ключевые входы:
Выгрузка продаж по SKU за 12–24 мес — ABC/XYZ классификация. [обязательно]
Остатки и оборачиваемость по SKU — Выявление неликвида. [обязательно]
Contribution margin по SKU (из PB-12) — Экономика позиций. [обязательно]
Данные о возвратах и рейтингах по SKU — Качество позиций. [желательно]
Обязательства перед поставщиками — Ограничения на вывод. [желательно]

|  | Проверка перед стартом Нужны продажи и остатки по SKU и маржинальность из PB-12. Чистка без данных о марже рискует убрать низкооборачиваемые, но высокомаржинальные позиции. |
| --- | --- |


### 4  Пошаговый процесс
Шаг 1. Собрать данные по SKU
Выгрузить продажи по позициям за 12–24 месяца.
Подтянуть остатки, оборачиваемость и маржу.
Учесть сезонность, чтобы не спутать её с неликвидом.
Шаг 2. Провести ABC-анализ
Классифицировать SKU по вкладу в выручку/маржу: A, B, C.
Определить, какая доля позиций даёт основную выручку.
Выделить длинный хвост слабых позиций.
Шаг 3. Провести XYZ-анализ
Классифицировать по стабильности спроса: X (стабильный), Y, Z (хаотичный).
Совместить ABC и XYZ в матрицу.
Определить управленческую стратегию для каждой ячейки.
Шаг 4. Наложить маржинальность
Пометить убыточные позиции (отрицательный CM2 из PB-12).
Найти высокомаржинальные позиции в хвосте — их не выводить.
Выявить AX-позиции (ядро) для приоритетной защиты.
Шаг 5. Сформировать план действий
Кандидаты на вывод: неликвид без стратегической ценности.
Кандидаты на репрайсинг: убыточные с потенциалом (в PB-13).
Кандидаты на развитие: A-позиции и точки роста.
Шаг 6. Учесть ограничения и передать
Проверить обязательства перед поставщиками и роль товаров в линейке.
Оценить эффект чистки на оборотный капитал (PB-36).
Передать план в закупки (PB-29) и ценообразование (PB-13).

### 5  Формулы и определения

| Показатель | Формула | Ориентир / комментарий |
| --- | --- | --- |
| ABC | Кумулятивная доля в выручке/марже | A≈80%, B≈15%, C≈5% |
| XYZ | Вариативность спроса (коэф. вариации) | X стабильный, Z хаотичный |
| Оборачиваемость | COGS / средние запасы | Низкая = неликвид |
| Замороженный капитал | Остатки неликвида × себестоимость | Высвобождается при чистке |
| Доля неликвида | SKU без продаж за период / всего | Цель: снижать |


### 6  Что получается на выходе (Deliverable)
D-34 «ABC/XYZ и план чистки ассортимента» (XLSX):
ABC/XYZ матрица — классификация SKU по вкладу и стабильности.
Маржинальный слой — подсветка убыточных и высокомаржинальных.
План вывода — кандидаты на удаление из каталога.
План репрайсинга — убыточные позиции для PB-13.
План развития — A-позиции и точки роста.
Эффект — высвобождение оборотного капитала.

### 7  Критерии приёмки
Работа считается выполненной, когда выполнены все условия ниже.
✓  Собраны продажи, остатки, оборачиваемость и маржа по SKU.
✓  Проведён ABC-анализ по вкладу в выручку/маржу.
✓  Проведён XYZ-анализ по стабильности спроса.
✓  Наложена маржинальность, помечены убыточные и защищённые позиции.
✓  Сформирован план: вывод, репрайсинг, развитие.
✓  План передан в PB-29 и PB-13, оценён эффект на оборотку.

### 8  Типовые ошибки

| Ошибка | Чем грозит | Как избежать |
| --- | --- | --- |
| Чистка только по обороту | Вывод высокомаржинального хвоста | Накладывать маржу на ABC |
| Спутать сезонность с неликвидом | Вывод сезонных бестселлеров | Учитывать сезонность в анализе |
| Игнорировать роль товара | Вывод входных/имиджевых позиций | Проверять роль в линейке |
| Чистка без оценки оборотки | Неясен финансовый эффект | Считать высвобождение капитала |
