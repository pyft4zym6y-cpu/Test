# PB-44 · Customer Journey Mapping

| Домен | Клиентский опыт |
| --- | --- |
| Срабатывает по правилам | R26 |
| Вопросы-источники | CU-009, CU-010, CU-024, PX-008 |
| Длительность | 3 недели |
| Deliverable | D-09 Customer Journey Map (Miro) |
| Владелец у клиента | CX-менеджер |


### 1  Зачем нужен этот плейбук
Клиент воспринимает бизнес не как набор отделов, а как единый путь — от первого касания до повторной покупки. Когда точки контакта проектируются изолированно, в этом пути возникают разрывы: реклама обещает одно, сайт показывает другое, поддержка не знает контекста. Customer Journey Mapping делает путь видимым целиком.
Плейбук строит карту пути клиента по этапам с точками контакта, эмоциями и барьерами, выявляя разрывы опыта и точки роста.

|  | Корневая проблема Нет карты пути клиента ни для одного сегмента. Точки контакта проектируются изолированно разными командами, из-за чего опыт рвётся: обещания не совпадают, переходы теряются, эмоциональные провалы никто не видит. |
| --- | --- |

Плейбук подключается, если в ходе Discovery подтвердился хотя бы один из триггеров ниже.

| Триггер (что услышали от клиента) | Правило |
| --- | --- |
| Нет CJM ни для одного сегмента | R26 |
| Точки контакта проектируются изолированно | — |
| Разрывы в опыте | — |


### 3  Что нужно на входе
Полный список требований к данным и доступам — в документе «Реестр данных и доступов». Ключевые входы:
Данные о пути клиента: источники, воронка, drop-off — Этапы и потери. [обязательно]
Точки контакта по каналам — Карта касаний. [обязательно]
Данные об эмоциях и барьерах (из PB-40) — Эмоциональная линия. [обязательно]
Метрики по этапам (конверсия, сроки) — Количественная база. [желательно]

### 4  Пошаговый процесс
Шаг 1. Определить сегмент и рамки карты
Выбрать сегмент/персону из PB-43 для картирования.
Задать границы пути: от осознания потребности до лояльности.
Определить каналы и точки контакта в охвате.
Шаг 2. Восстановить этапы пути
Разложить путь на этапы: осознание, поиск, выбор, покупка, использование, повтор.
Для каждого этапа определить действия и цели клиента.
Наложить данные аналитики: где реальные переходы и отвалы.
Шаг 3. Нанести точки контакта
Собрать все касания бренда на каждом этапе across каналов.
Оценить согласованность сообщений между точками.
Найти разрывы и дублирования.
Шаг 4. Добавить эмоции и барьеры
Нанести эмоциональную линию по данным из PB-40.
Отметить точки боли и барьеры на каждом этапе.
Выделить моменты истины — критичные для решения.
Шаг 5. Найти точки роста
Определить, где устранение разрыва даёт максимальный эффект.
Приоритизировать улучшения по влиянию.
Связать с CRO-гипотезами (PB-15).
Шаг 6. Оформить и передать
Собрать CJM в Miro как рабочий артефакт.
Отразить на листе «50 CJM».
Передать точки роста в PB-15, PB-47, PB-45.

### 5  Формулы и определения

| Показатель | Формула | Ориентир / комментарий |
| --- | --- | --- |
| Конверсия этапа | Перешли дальше / вошли на этап | Выявление узких мест |
| Согласованность | Точек с единым сообщением / всего | Целостность опыта |
| Эмоциональный провал | Этапы с негативной эмоцией | Приоритет для улучшения |
| Время этапа | Медианная длительность этапа | Затянутые этапы = трение |


### 6  Что получается на выходе (Deliverable)
D-09 «Customer Journey Map» (Miro):
Этапы пути — действия и цели клиента по этапам.
Точки контакта — касания бренда с оценкой согласованности.
Эмоциональная линия — эмоции и барьеры по этапам.
Моменты истины — критичные точки принятия решения.
Точки роста — приоритизированные улучшения опыта.

### 7  Критерии приёмки
Работа считается выполненной, когда выполнены все условия ниже.
✓  Выбран сегмент и заданы рамки карты.
✓  Восстановлены этапы пути с данными аналитики.
✓  Нанесены точки контакта с оценкой согласованности.
✓  Добавлены эмоции и барьеры из исследования.
✓  Определены приоритизированные точки роста.
✓  Точки роста переданы в PB-15, PB-47, PB-45.

### 8  Типовые ошибки

| Ошибка | Чем грозит | Как избежать |
| --- | --- | --- |
| CJM из головы, без данных | Карта фантазий, а не реальности | Опираться на аналитику и PB-40 |
| Путь без эмоций | Упускаются провалы восприятия | Наносить эмоциональную линию |
| Карта ради карты | Красивый артефакт без действий | Выводить приоритизированные точки роста |
| Одна карта для всех сегментов | Смешение разных путей | Картировать по сегментам |
