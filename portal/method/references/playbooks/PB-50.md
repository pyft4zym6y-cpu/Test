# PB-50 · Brand Measurement

| Домен | Аналитика |
| --- | --- |
| Срабатывает по правилам | R36 · R37 |
| Вопросы-источники | BR-030, BR-031, BR-032, BI-007, BI-008 |
| Длительность | 2 недели |
| Deliverable | D-20 Дашборд бренд-метрик (BI) |
| Владелец у клиента | Аналитик / маркетинг |


### 1  Зачем нужен этот плейбук
Бренд, который не измеряется, финансируется по остаточному принципу и первым попадает под нож при сокращении бюджета. Brand Measurement превращает бренд из «неосязаемого» в набор отслеживаемых метрик: брендовый спрос, ценовая премия, узнаваемость — то, что доказывает вклад бренда в деньги.
Плейбук задаёт систему бренд-метрик, снимает baseline и строит дашборд, связывающий силу бренда с бизнес-результатом.

|  | Корневая проблема Метрики бренда не измеряются, поэтому бренд невозможно защитить в бюджете и им невозможно управлять. Нет ценовой премии, нет данных о брендовом спросе, инвестиции в бренд финансируются по остатку и режутся первыми. |
| --- | --- |


### 2  Когда подключать: симптомы и триггеры
Плейбук подключается, если в ходе Discovery подтвердился хотя бы один из триггеров ниже.

| Триггер (что услышали от клиента) | Правило |
| --- | --- |
| Метрики бренда не измеряются | R36 |
| Нет ценовой премии | R37 |
| Бренд финансируется по остатку | — |


### 3  Что нужно на входе
Полный список требований к данным и доступам — в документе «Реестр данных и доступов». Ключевые входы:
Данные брендового поиска и прямого трафика — Brand demand. [обязательно]
Данные о ценовой премии к конкурентам — Price premium. [обязательно]
Awareness/восприятие (опрос) — Brand awareness baseline. [желательно]
NPS и доля повторных покупок — Сила бренда. [желательно]

### 4  Пошаговый процесс
Шаг 1. Определить систему бренд-метрик
Выбрать метрики: брендовый поиск, прямой трафик, ценовая премия, узнаваемость, NPS.
Связать каждую метрику с бизнес-эффектом.
Задать источники данных для каждой.
Шаг 2. Снять baseline
Замерить текущий уровень брендового спроса и прямого трафика.
Оценить ценовую премию к конкурентам (связь с PB-13).
При наличии — снять узнаваемость и восприятие через опрос.
Шаг 3. Связать бренд с деньгами
Показать корреляцию брендового спроса с выручкой и маржой.
Оценить, какую долю выручки обеспечивают лояльные/брендовые клиенты.
Обосновать вклад бренда в снижение CAC.
Шаг 4. Построить дашборд бренд-метрик
Собрать метрики в единую панель с динамикой.
Задать целевые значения и триггеры внимания.
Интегрировать в общий BI-слой (PB-11).
Шаг 5. Задать ритм измерения
Определить частоту снятия каждой метрики.
Заложить точки корреляции с активностями бренда.
Связать с внедрением бренда (PB-49).
Шаг 6. Связать со смежными плейбуками
Ценовая премия → PB-13.
Внедрение бренда → PB-49.
Дашборды → PB-11.

### 5  Формулы и определения

| Показатель | Формула | Ориентир / комментарий |
| --- | --- | --- |
| Брендовый спрос | Брендовые запросы / все запросы | Рост = усиление бренда |
| Прямой трафик | Доля прямых заходов | Индикатор узнаваемости |
| Ценовая премия | (Наша цена − конкурент) / конкурент | Монетизация бренда |
| Доля брендовой выручки | Выручка лояльных / общая | Устойчивость к CAC-инфляции |


### 6  Что получается на выходе (Deliverable)
D-20 «Дашборд бренд-метрик + baseline» (BI):
Система метрик — перечень бренд-метрик и их бизнес-связь.
Baseline — текущие значения ключевых показателей.
Связь с деньгами — корреляция бренда с выручкой и CAC.
Дашборд — панель метрик с динамикой и целями.
Регламент измерения — частота и точки корреляции.

### 7  Критерии приёмки
Работа считается выполненной, когда выполнены все условия ниже.
✓  Определена система бренд-метрик, связанных с бизнес-эффектом.
✓  Снят baseline брендового спроса и ценовой премии.
✓  Показана связь бренда с выручкой и CAC.
✓  Построен дашборд с целевыми значениями.
✓  Задан ритм измерения метрик.
✓  Ценовая премия согласована с PB-13, дашборд — с PB-11.

### 8  Типовые ошибки

| Ошибка | Чем грозит | Как избежать |
| --- | --- | --- |
| Не измерять бренд | Финансирование по остатку, урезание | Дать бренду метрики и baseline |
| Метрики без связи с деньгами | Невозможно защитить бюджет | Связать каждую метрику с эффектом |
| Разовый замер | Нет динамики и доказательства эффекта | Регулярное измерение |
| Игнорировать ценовую премию | Теряется главный монетизируемый эффект | Считать премию к конкурентам |
