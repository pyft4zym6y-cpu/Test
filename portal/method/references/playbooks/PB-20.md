# PB-20 · Процесс возвратов и обратной логистики

| Домен | Операции |
| --- | --- |
| Срабатывает по правилам | по итогам диагностики |
| Вопросы-источники | PX-022, OP-016, IN-038, CU-019 |
| Длительность | 3 недели |
| Deliverable | D-54 Программа снижения возвратов и отказов (DOC / XLSX) |
| Владелец у клиента | COO / клиентский сервис |


### 1  Зачем нужен этот плейбук
Возвраты — это не только логистика, но и удар по марже и сигнал о проблемах продукта или ожиданий. Высокая доля возвратов тихо съедает прибыль, а из ЕС возвраты могут быть экономически невозможны. Процесс возвратов делает обратный поток управляемым, а его причины — видимыми.
Плейбук выстраивает процесс возвратов и обратной логистики, анализирует причины возвратов и их экономику, снижая долю и стоимость возвратов.

|  | Корневая проблема Возвраты не управляются: доля высокая, причины не анализируются, процесс медленный. Возвраты бьют по марже, а из ЕС могут быть вовсе неокупаемы. Корневые причины (несоответствие ожиданий, качество) не устраняются. |
| --- | --- |


### 2  Когда подключать: симптомы и триггеры
Плейбук подключается, если в ходе Discovery подтвердился хотя бы один из триггеров ниже.

| Триггер (что услышали от клиента) | Правило |
| --- | --- |
| Высокая доля возвратов | — |
| Возвраты из ЕС экономически невозможны | — |
| Возвраты бьют по марже | — |


### 3  Что нужно на входе
Полный список требований к данным и доступам — в документе «Реестр данных и доступов». Ключевые входы:
Данные о возвратах: доля, причины, стоимость — Анализ возвратов. [обязательно]
Текущий процесс обработки возврата — Узкие места. [обязательно]
Причины возвратов по категориям — Корневые причины. [обязательно]
Логистика возвратов и тарифы — Стоимость обратного потока. [желательно]

### 4  Пошаговый процесс
Шаг 1. Проанализировать возвраты
Собрать данные: доля возвратов, стоимость, причины.
Сегментировать возвраты по категориям и SKU.
Оценить влияние возвратов на маржу (связь с PB-12).
Шаг 2. Выявить корневые причины
Классифицировать причины: размер, качество, несоответствие описанию, ожидания.
Связать с данными поддержки и отзывов (PB-45).
Определить топ-причины по частоте и стоимости.
Шаг 3. Устранить причины на входе
Улучшить контент карточек под частые причины (размерные сетки, фото).
Скорректировать ожидания в описаниях.
Передать проблемы качества в продукт/закупки.
Шаг 4. Оптимизировать процесс возврата
Упростить и ускорить процесс для клиента.
Оптимизировать обработку и обратную логистику.
Особое внимание — возвратам из ЕС.
Шаг 5. Заложить экономику
Смоделировать эффект снижения возвратов на маржу.
Оптимизировать политику возвратов под экономику.
Сбалансировать клиентский опыт и затраты.
Шаг 6. Оформить и связать
Собрать процесс возвратов и план снижения.
Причины → PB-45 (VoC), продукт.
Логистика → PB-19 (фулфилмент).

### 5  Формулы и определения

| Показатель | Формула | Ориентир / комментарий |
| --- | --- | --- |
| Return rate | Возвраты / заказы | Ключевая метрика |
| Стоимость возврата | Логистика + обработка + потеря товарного вида | Влияние на маржу |
| Return-adjusted margin | Маржа с учётом возвратов | Реальная прибыльность |
| Причинная доля | Возвратов по причине / всего | Приоритет устранения |


### 6  Что получается на выходе (Deliverable)
D-34 «Процесс возвратов» (DOC) + экономика:
Анализ возвратов — доля, стоимость, сегментация.
Корневые причины — классификация и топ-причины.
План устранения — улучшения контента и продукта.
Оптимизированный процесс — обработка и обратная логистика.
Экономика — эффект снижения на маржу.

### 7  Критерии приёмки
Работа считается выполненной, когда выполнены все условия ниже.
✓  Проанализированы доля, стоимость и причины возвратов.
✓  Выявлены корневые причины по частоте и стоимости.
✓  Составлен план устранения причин на входе.
✓  Оптимизирован процесс возврата, включая ЕС.
✓  Смоделирован эффект снижения на маржу.
✓  Причины переданы в PB-45, логистика — в PB-19.

### 8  Типовые ошибки

| Ошибка | Чем грозит | Как избежать |
| --- | --- | --- |
| Обрабатывать возвраты, не устраняя причины | Доля не снижается | Устранять корневые причины на входе |
| Игнорировать влияние на маржу | Скрытая эрозия прибыли | Считать return-adjusted margin |
| Единая политика без экономики | Убыточные возвраты из ЕС | Оптимизировать под экономику |
| Сложный процесс возврата | Недовольство клиентов | Упрощать клиентский путь |
