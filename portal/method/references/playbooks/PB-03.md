# PB-03 · Channel Strategy (каналы привлечения)

| Домен | Маркетинг |
| --- | --- |
| Срабатывает по правилам | R39 |
| Вопросы-источники | MK-001…MK-010, CI-009, CM-009 |
| Длительность | 3 недели |
| Deliverable | D-51 Стратегия каналов привлечения (DOC / XLSX) |
| Владелец у клиента | Маркетинг-директор |


### 1  Зачем нужен этот плейбук
Бюджет на привлечение почти всегда ограничен, а каналов много. Без стратегии он распыляется: деньги идут туда, где привыкли, а не туда, где эффективно, и каналы конкурентов остаются неиспользованными. Channel Strategy определяет, какие каналы работают, какова их роль и как распределить бюджет.
Плейбук анализирует эффективность каналов, их роль в пути к покупке и юнит-экономику, и строит стратегию распределения бюджета с учётом каналов конкурентов.

|  | Корневая проблема Бюджет распыляется по каналам без стратегии: тратится по привычке и по blended-метрикам, роль каналов в пути неясна, прибыльность по каналам не считается, каналы конкурентов игнорируются. |
| --- | --- |


### 2  Когда подключать: симптомы и триггеры
Плейбук подключается, если в ходе Discovery подтвердился хотя бы один из триггеров ниже.

| Триггер (что услышали от клиента) | Правило |
| --- | --- |
| Сообщения в каналах не согласованы | R39 |
| Распыление бюджета по каналам | — |
| Каналы конкурентов не используются | — |


### 3  Что нужно на входе
Полный список требований к данным и доступам — в документе «Реестр данных и доступов». Ключевые входы:
Данные о расходах и результатах по каналам — Эффективность каналов. [обязательно]
Атрибуция и путь к покупке — Роль каналов. [обязательно]
Каналы конкурентов (из PB-41) — Channel gap. [обязательно]
Юнит-экономика по каналам (из PB-12) — Прибыльность каналов. [желательно]

|  | Проверка перед стартом Нужна достоверная атрибуция (PB-10) и юнит-экономика по каналам (PB-12). Без них решения о бюджете принимаются по blended-метрикам, которые скрывают убыточные каналы. |
| --- | --- |


### 4  Пошаговый процесс
Шаг 1. Собрать данные по каналам
Собрать расходы и результаты по каждому каналу.
Подтянуть атрибуцию и путь к покупке.
Подтянуть юнит-экономику по каналам из PB-12.
Шаг 2. Оценить роль каналов
Определить роль каждого канала: привлечение, прогрев, закрытие.
Оценить каналы по прибыльности, а не только по объёму.
Выявить убыточные и недоинвестированные каналы.
Шаг 3. Проанализировать каналы конкурентов
Взять данные о каналах конкурентов из PB-41.
Найти channel gap: где конкуренты есть, а бренд нет.
Оценить потенциал новых каналов.
Шаг 4. Построить стратегию распределения
Задать целевое распределение бюджета по каналам и ролям.
Приоритизировать по прибыльности и потенциалу.
Заложить тестовый бюджет на новые каналы.
Шаг 5. Согласовать с коммуникацией
Обеспечить единые сообщения across каналов (PB-47).
Задать роль контента в каждом канале.
Связать с retention-каналами (PB-08).
Шаг 6. Оформить и задать измерение
Собрать стратегию каналов с распределением бюджета.
Задать метрики эффективности по каналам.
Определить цикл пересмотра.

### 5  Формулы и определения

| Показатель | Формула | Ориентир / комментарий |
| --- | --- | --- |
| ROI канала | Маржа канала / затраты канала | Прибыльность, не ROAS |
| CAC по каналу | Затраты канала / новые клиенты | Сравнение каналов |
| Channel gap | Каналы конкурентов − наши | Незанятые каналы |
| Роль в пути | Позиция канала в атрибуции | Привлечение vs закрытие |


### 6  Что получается на выходе (Deliverable)
«Channel Strategy» (DOC/XLSX):
Данные по каналам — расходы, результаты, атрибуция, экономика.
Оценка ролей — роль и прибыльность каждого канала.
Channel gap — каналы конкурентов и потенциал новых.
Распределение бюджета — целевое распределение по каналам.
Метрики — показатели эффективности и цикл пересмотра.

### 7  Критерии приёмки
Работа считается выполненной, когда выполнены все условия ниже.
✓  Собраны данные по каналам с атрибуцией и экономикой.
✓  Оценены роль и прибыльность каждого канала.
✓  Проанализированы каналы конкурентов, найден channel gap.
✓  Построено целевое распределение бюджета.
✓  Коммуникация согласована across каналов.
✓  Заданы метрики и цикл пересмотра.

### 8  Типовые ошибки

| Ошибка | Чем грозит | Как избежать |
| --- | --- | --- |
| Решения по blended-метрикам | Скрытые убыточные каналы | Считать экономику по каналам |
| Оценивать каналы по объёму | Игнорируется прибыльность | Оценивать по марже/ROI |
| Игнорировать роль в пути | Недооценка прогревающих каналов | Учитывать атрибуцию |
| Не тестировать новые каналы | Упущенные возможности | Закладывать тестовый бюджет |
