# Доменный плейбук 07 · SEO-аудит

**Домен Commerce OS:** SEO

Плейбук: SEO-аудит
  Раскрывает 1.2 главного документа до полного отраслевого стандарта. По отчёту,
  органический трафик формирует 40–80% долгосрочного роста выручки — это не
  «ещё один канал», а фундаментальный слой видимости бизнеса.
## I. Методология и подготовка
   Режимы: lightweight (техническая проверка, покрыта 1.2 главного документа) /
   deep-dive (полная стратегия видимости, объём не оценён отчётом количественно,
   ориентир — 150-250 стр. по масштабу каталога)

   Команда: SEO-специалист + доступ к разработчику для внедрения технических
   рекомендаций

   Предварительное условие: доступ к Search Console минимум за 3-6 месяцев
   истории для анализа трендов, не только снимка на сегодня
## II. Индексация и краулинг (расширенная версия)
   Log-file анализ — как реально ведёт себя поисковый робот (не только то, что
   показывает Search Console)

   Моделирование crawl budget — сколько страниц робот успевает обходить за цикл
   относительно общего размера сайта
## III. Архитектура сайта и IA
Прямое продолжение 1.2 главного документа (блок А) — дерево категорий, глубина
вложенности, логика URL. В плейбуке — с расчётом конкретной рекомендованной
структуры для каталога данного масштаба, не только диагностикой проблем.
## IV. Фасетная навигация и фильтры
Углублённая версия — конкретная матрица “какие комбинации фильтров
индексировать” по реальному объёму поискового спроса на каждую комбинацию (не
теоретически, а по данным Search Console/подбора ключевых слов).
## V. Техническая производительность
Core Web Vitals по каждому шаблону страниц отдельно (главная/категория/карточка), а
не усреднённо — узкое место может быть только в одном шаблоне.
## VI. On-page оптимизация по типам страниц
   Title/meta description/H1 — паттерны и уникальность по шаблонам

   Оптимизация под коммерческие и информационные намерения запроса
   раздельно
## VII. Контентная стратегия и семантическое ядро
   Кластеризация запросов и сопоставление с существующими страницами — где
   кластер спроса есть, а страницы нет (content gap)

   Покрытие воронки: транзакционные / сравнительные / информационные запросы
## VIII. Структурированные данные и GEO/AEO
Прямое продолжение 1.3 главного документа — здесь добавляется системный аудит
по всему каталогу, не выборочно.
## IX. Локальное и международное SEO
Hreflang, мультирегиональность — прямая связь с решением 2.3 п.4 главного
документа (домен/поддомен/подпапка) — техническая реализация SEO-части
выбранного варианта.
## X. Ссылочный профиль
Базовый аудит авторитетности домена, качество и токсичность входящих ссылок,
возможности для наращивания (партнёрства, упоминания).
## XI. Конкурентный SEO-анализ
Share of voice по ключевым кластерам запросов относительно конкурентов из
плейбука №1 — где конкурент видим, а клиент нет.
## XII. Мониторинг позиций и отчётность
Регулярное отслеживание позиций по приоритетным кластерам, разделение на
“потеряли” / “выросли” / “стабильно” для быстрой реакции.
## XIII. Скоринг и приоритизация
Матрица: объём спроса кластера × текущая позиция × техническая сложность
внедрения — приоритет высокочастотным кластерам с низкой сложностью правки.
## XIV. Roadmap-шаблон SEO-инициатив
Технические фиксы (быстрые) → архитектурные изменения (средний срок, требуют
разработки) → контентная стратегия (длинный горизонт, накопительный эффект).
## XV. Инструменты
Google Search Console, PageSpeed Insights · краулеры (Screaming Frog и аналоги) ·
сервисы кластеризации запросов
## XVI. Каденция мониторинга
