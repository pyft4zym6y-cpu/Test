Закрывает замечания №6, №7, J-02. Ключевая специфика AI-SaaS: **COGS растёт с использованием**
(токены = метрируемая себестоимость), а не амортизируется масштабом. Источники: a16z «New
Business of AI» (2020), Bessemer (2026), Drivetrain, ICONIQ (2026).

## Модель стоимости одного аудита

```
Cost per Audit =
    LLM-токены (input×цена + output×цена)      ← крупнейший переменный драйвер
  + web_search / vision-вызовы
  + crawl (Playwright compute, время)
  + инфраструктура (хост движка, PDF-рендер)
  + storage (results/, Supabase)
  + внешние API (Serpstat/SimilarWeb/PSI — если премиум)
  + human-in-the-loop (review/approval — раздел 31)
  + report generation
  + аллокация sales/onboarding
```

## Маржа

```
Gross Margin = (Цена − полная себестоимость) / Цена
Contribution Margin, LTV:CAC, CAC-payback — стандартно (см. модуль unitecon.ts, применить к себе)
```

**Бенчмарки (для позиционирования в DD):**
- AI/ML-бизнесы: gross margin ~**50–60%** vs классический SaaS **60–80%+** (a16z, 2020).
- Bessemer (2026): AI ~50–60% vs SaaS 80–90%.
- ICONIQ (2026): доля inference-затрат растёт ~20%→23% по мере зрелости.
- Sarah Wang (a16z): аномально ВЫСОКая маржа — «оранжевый флаг» (недоинвестирование в качество).

## Крупнейший рычаг маржи — model routing

Разброс цен внутри вендора часто **5×+** (дешёвый tier vs frontier). Роутить простые под-задачи
на дешёвую модель, frontier — только на сложные шаги; prompt caching, лимит длины вывода,
батчинг, short-circuit при высокой уверенности. Целевая маржа для здорового вида в DD: **>60–70%**.
