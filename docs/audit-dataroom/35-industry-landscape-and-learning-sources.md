## Конкуренты / смежные продукты (AI-аудит e-commerce и сайтов)

| Продукт | Что делает | Позиционирование vs нас |
|---------|-----------|--------------------------|
| ConversionBox — AI Visibility Audit | видимость бренда в AI-выдаче (AEO/GEO), crawlability, schema | у нас GEO/AEO — один из 19 блоков, а не весь продукт |
| Yotpo Discover | почему AI рекомендует конкурента; индексация в ChatGPT/Gemini/AI Overviews | у нас — целостный аудит, не только AI-видимость |
| Semrush Site Audit | техническое здоровье сайта в реальном времени | у нас — от техники до стратегии/экономики |
| Heybooster | «виртуальный аналитик» для e-commerce маркетологов | у нас — глубина T1–T4 + честность данных |
| SEO HERO (Shopify) | AI SEO/CRO-анализ | точечный, не система |
| Deltologic | AI & Automation Audit (агентская модель) | сервис, не продукт |

## Кого читать (по темам)

**AI evals / оценка LLM (ядро для наших разделов 20–22):**
- **Hamel Husain** — hamel.dev (гайд LLM-as-a-Judge: hamel.dev/blog/posts/llm-judge/), рассылка hamelhusain.substack.com.
- **Shreya Shankar** — соавтор LLM Evals FAQ, методология оценки.
- **Eugene Yan** — eugeneyan.com (обзор LLM-evaluators, инструмент AlignEval).
- **Nathan Lambert** — рассылка «Interconnects» (interconnects.ai): evals, анализ моделей.
- **The AI Evaluation Newsletter** — aievaluation.substack.com.
- **Hugging Face LLM Evaluation Guidebook** + список **benchflow-ai/awesome-evals** (GitHub).

**E-commerce CRO / аудит (ядро для методологии и бенчмарков):**
- **Baymard Institute** (Christian Holst) — baymard.com: ~200k часов UX-исследований, эталон
  для доказательных эвристик (наш Benchmark Register опирается на них).
- **Peep Laja** — CXL / Wynter: методология экспериментов.
- **Brian Massey** (Conversion Sciences), **Ayat Shukairy** (Invesp), **Laura Stude** (Surefoot).
- Обзоры: Dynamic Yield «Top 15 CRO Thought Leaders», WiserNotify «25 Elite CRO Experts».

**AI governance / responsible AI (для разделов 20, 22, 29):**
- **NIST AI RMF** — nist.gov/itl/ai-risk-management-framework (якорный фреймворк).
- **IAPP** — iapp.org (приватность + AI-governance, сертификации).
- Каталог: Jurgen Appelo «100 Best AI Newsletters on Substack».
