## Процедуры

- **Joiner (онбординг):** минимальный набор прав под роль; MFA обязателен; запись в матрицу.
- **Mover:** пересмотр прав при смене роли (убрать лишнее).
- **Leaver (оффбординг):** отзыв ВСЕХ доступов + **ротация общих секретов**, к которым имел
  доступ (`AUDIT_SERVER_TOKEN`, API-ключи), в тот же день; отметка в матрице.
- **Access review:** ежеквартально — подтвердить, что список актуален (доказательство SOC 2/ISO).
- **Ротация секретов:** график [Заполнить] + при каждом leaver/инциденте.

## Definition of Done

процедуры joiner/mover/leaver задокументированы; ротация секретов имеет график и журнал.
