# Бесплатные внешние инструменты для теста

Срез 26.08.2026. Только то, что **выложено специально и открыто** — лид-магниты
вендоров, осознанный open-source агентств и практиков, публичные шаблоны и
бесплатные API-тиры. Ничего «забытого незакрытым»: берём то, что дали, а не то,
что недоглядели.

Зачем нам: проверить на живых данных функционал, который мы собираемся строить в
движке, не платя за подписки и не заводя аккаунтов на боевых сервисах.

---

## 1. Золотая жила — публичный код практиков

### Lee Foot · `searchsolved/search-solved-public-seo`
**100+ SEO-инструментов, MIT.** Ровно тот случай, о котором речь: специалист
писал их для своей работы и выложил целиком. Большинство — Streamlit-приложения
и Colab-ноутбуки, то есть **открываешь в браузере и гоняешь на своих данных, без
установки.** Прямой мэппинг на наши аудиты:

| Инструмент | Что делает | Наш домен |
|---|---|---|
| Semantic Clustering Tool | Кластеризация ключей на sentence-transformers (CLI/Colab) | seo |
| SERP Clustering at Scale / API | Кластеризация по URL из выдачи (Python/FastAPI) | seo |
| Striking Distance V1/V2 | Позиции 4–20 + проверка наличия ключа в title/H1/тексте | seo |
| Keyword Cannibalization | Конкурирующие за один запрос страницы | seo |
| Content Decay Analyzer | Страницы, теряющие трафик | seo |
| Core Update Analyser · Delta Audit | Изменения ранжирования по папкам, всплески в GSC | seo |
| Share of Voice | Доля органического трафика — то, чего нам не хватает в PR-блоке | market |
| Backlink Intersector · Link Quality Analyzer | Ссылочные возможности через конкурентов, статусы ссылок | seo |
| N-gram SERP Extractor · PAA Scraper | N-граммы и People-Also-Ask из выдачи | seo |
| Page Intent Classifier | Инфо / транзакционный / навигационный | seo/website |
| Product Title Gap · Competitor Gap Finder | Разрыв в заголовках товара против конкурентов | product |
| Meta Description Grader/Rewriter | Скоринг и переписывание мета | seo |
| Reading Score Analyzer | Flesch-читаемость | seo |
| Visualise Internal Links · GSC Coverage | Treemap перелинковки, карта индексации (Colab) | website/seo |
| Template Fingerprinting | Определение шаблона страницы через ML | website |

**Как тестить:** брать по одному инструменту под конкретный блок аудита, гонять
на своём тестовом домене, сверять с тем, что выдаёт наш движок. Код читается —
годится и как эталон реализации, и как источник идей проверок.

### Brainlabs · `Brainlabs-Digital/Google-Ads-Scripts`
Агентство открыло свои боевые Google Ads Scripts (GPL-2.0): папки Analyzing,
Bidding, Managing, Monitoring, Reporting, Testing. Запускаются read-only в
Google Ads Scripts — **клиент запускает у себя, доступы нам не нужны.**

### Прочий агентский open-source (уже был в наших разборах)
`optmyzr-skills/google-ads-audit` (42 проверки в 14 категориях),
Google Ads Scripts от практиков — `tcaslan`, `Hassanelsisi`, `GeertGR`
(аудит аккаунта → Google Sheet / HTML-отчёт), `google/disapproved-ads-auditor`.

### Colab-ноутбуки
Публичные блокноты по кластеризации запросов и анализу GSC
(`razvanantonescu/seo-keyword-clustering`, `jfaccioli/seo-keyword-clusters`,
готовый Colab «GSC Analysis: Query Count, N-grams and Clustering»). Открыл,
подключил свой GSC — считает бесплатно на инфраструктуре Google.

## 2. Бесплатные инструменты вендоров без оплаты

Урезанные, но рабочие версии боевого софта — вендор отдаёт функционал ради лида.

| Инструмент | Что тестим | Лимит |
|---|---|---|
| **Google Search Console / Trends / Keyword Planner** | Реальные запросы, показы, позиции, сезонность | Безлимит, свои сайты |
| **Bing Webmaster Tools** | То же для Bing, плюс свой keyword research | Бесплатно |
| **Ahrefs Webmaster Tools** | Аудит своего сайта, ссылочный профиль | Бесплатно для своих доменов |
| **Moz Link Explorer + MozBar** | DA/PA, беглый обзор ссылок конкурентов | 10 запросов/мес |
| **Ubersuggest** (Neil Patel) | Ключи, беглый аудит, ссылки | 3 запроса/день, без карты |
| **Screaming Frog (free)** | Краул до 500 URL — эталон, с которым сверять свой обход | 500 URL, бессрочно |
| **SEOquake / SEOquake-подобные расширения** | On-page аудит и метрики прямо в браузере | Бесплатно |
| **Google Rich Results Test / Schema Markup Validator** | Валидация нашей и чужой разметки | Безлимит |

## 3. Технические утилиты Merkle и практиков (TechnicalSEO.com)

Max Prin / Merkle (Dentsu) — самый используемый бесплатный набор в индустрии:
генератор Schema.org (JSON-LD), тестер `robots.txt`, Fetch & Render,
генератор и парсер `sitemap`, hreflang-генератор. Всё бесплатно, без аккаунта.
Плюс `aleydasolis.com` — hreflang- и redirect-генераторы, `learningseo.io` —
курируемый список проверенных бесплатных инструментов.

**GEO/AEO:** бесплатные валидаторы `llms.txt` — llms-txt.io/validator,
Rankability, MRS Digital, llmtxt.info. Проверить наш GEO-блок против чужой
эталонной проверки.

## 4. Публичные шаблоны отчётов (Looker Studio)

Готовые бесплатные дашборды GSC + GA4 — берёшь шаблон, подключаешь свои
коннекторы, смотришь, как индустрия компонует отчёт клиенту:
Catchr (SEO Overview, GSC), MetricNexus (GSC + GA4), Scale Growth Digital
(5-страничный), плюс галерея примеров Data Bloo. Полезно как референс вёрстки
нашего портала отчётов, а не только как инструмент.

## 5. Бесплатные API-тиры для программного теста

Проверить интеграцию в воркер, не заводя платного аккаунта:

| API | Бесплатно | Для чего |
|---|---|---|
| **PageSpeed Insights API** | Безлимит, ключ Google | Lighthouse-as-a-service + поле CrUX |
| **CrUX API** | Безлимит, ключ Google | Полевые Core Web Vitals по любому домену |
| **GSC API / Indexing API** | Свои сайты | Реальные search-данные, ускорение индексации |
| **DataForSEO Sandbox** | $1 кредита на тест формата ответа | SERP/ключи/ссылки/Merchant — проверить структуру до $50-депозита |
| **SerpApi** | 250 запросов/мес постоянно | SERP-парсинг |
| **Serper** | 2 500 кредитов разово | Google-выдача |
| **SE Ranking trial** | 14 дней, 100k кредитов | Полный прогон на реальном проекте |

## Как этим пользоваться, не наступая на грабли

- **Граница простая:** запускаем то, что автор выложил как инструмент/лид-магнит/
  шаблон. Не трогаем чужие внутренние дашборды, открытые эндпойнты и данные,
  которые не предназначались публике, — даже если технически доступны.
- **Лицензии:** MIT (Lee Foot) — можно и подсматривать, и переиспользовать код;
  GPL-2.0 (Brainlabs) — переиспользование кода тянет копилефт, для встраивания в
  наш продукт читать отдельно, для «запустить и посмотреть» — без ограничений.
- **Порядок теста:** сначала Lee Foot под каждый блок аудита (прямая калибровка
  нашего движка против чужой реализации), параллельно бесплатные API в песочнице,
  затем вендорские утилиты как эталон, с которым сверяем свои проверки.

Ссылки и лимиты — на 26.08.2026; бесплатные тиры вендоры меняют часто, сверять
перед прогоном.
